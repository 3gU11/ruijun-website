# 新闻视频上传与发布 · 操作手册

> 适用：往官网「视频新闻」栏目维护视频分享卡片。
> 前提：后台已启动（双击 `启动CMS官网维修系统.bat`），用有编辑权限的账号登录 `http://127.0.0.1:8055/admin`。

---

## 先分清两条内容线

| 内容 | 组成 | 入口 |
| --- | --- | --- |
| **视频分享** | **只有视频**，没有文章 | 视频新闻 → 视频分享内容 |
| **动态新闻** | **文章 + 图片**，没有视频 | 视频新闻 → 动态新闻内容 |

视频分享的标题、日期、封面、字幕都来自视频素材本身。动态新闻的文章和图片不要和视频分享混在一起。

---

## 视频分享的规则

- **可以只有视频。** 上传或选择视频后，官网就能生成一张卡片。
- **视频素材上传即发布。** 不需要送审、审批或发布队列。
- **一张卡片可以换视频。** 修改时直接选择另一条已上传视频即可。
- **删除就是整条删除。** 视频分享只有视频，删除后视频素材和卡片一起从官网移除。
- **保存分两步。** 先点“保存修改内容”，再填写“保存名称”并点“上传媒体资源”。保存名称是必填项。上传成功后会弹出绿色提示条。
- **官网播放有返回键。** 点击视频卡片会在新闻页内打开播放器，左上角可直接“返回视频分享”，不会跳到裸视频文件。

> 视频分享不需要“素材送审 → 审核队列 → 发布队列”这一套。视频上传成功就可用。

## 一、新增视频分享

### 入口

左侧栏 **视频新闻** → **视频分享内容** → 右上角 **新增视频分享**。

也可以从新闻页画布工具栏点 **新增视频分享**，效果相同。

### 选择视频来源

新增弹窗里有两个来源：

| 来源 | 用法 |
| --- | --- |
| **从电脑选择文件** | 选本地 MP4 / WebM，最大 500 MB；选完自动读取尺寸和时长。 |
| **使用系统已上传媒体** | 直接选“媒体资产”里已经上传过的视频，不重复占空间。 |

如果选到的视频已经属于另一张卡片，系统会自动切到那张卡片的“修改”状态，避免同一视频出现两张重复卡片。

### 视频素材必填项

表单和“媒体资产”的上传表单保持一致。使用范围、官网展示位置、所属页面/段落已经自动固定为：

- 使用范围：**视频新闻**
- 官网展示位置：**视频分享列表**
- 所属页面 / 段落：**news / video-sharing**

需要填写或确认：

| 字段 | 说明 |
| --- | --- |
| **素材标题（也是卡片标题）** | 官网卡片上显示的文字，必填。 |
| **显示顺序** | 同一位置多条视频时的排序，0 开始。 |
| **版权状态** | 自有素材 / 已获许可 / 已授权公开 / 待确认，必选。 |
| **发布后允许此位置使用** | **保持勾选**；不勾选时官网不会显示这条视频。 |
| **替代文本** | 简述画面内容，便于检索与无障碍访问。 |
| **素材说明** | 选填。 |
| **视频封面** | 可选。不选就用视频首帧。 |
| **自动播放 / 默认静音 / 循环播放** | 视频分享列表按需勾选；自动播放时建议静音。 |
| **字幕或文字稿** | 视频分享不要求，可留空。 |
| **授权与来源说明** | 拍摄来源、许可证、授权范围。 |

### 保存

1. 点击底部的 **保存修改内容**。这一步会把视频和卡片信息写入后台。
2. 填写 **保存名称**（必填，例如“2026 年 11 月展会视频”）。
3. 点击 **上传媒体资源**。

上传成功后，弹窗会自动关闭，页面底部会出现绿色提示：**“媒体资源已上传，保存名称：……”**。

> 顺序不能反：没有点“保存修改内容”时，“上传媒体资源”是灰的；没有填写保存名称时，也不能上传。
> 如果点“保存修改内容”后没有反应，错误提示会显示在弹窗底部按钮旁边，红色文字就是原因。

## 二、修改视频分享

**视频分享内容** 列表里点某张卡片的 **修改**。

可以：

- 改素材标题（也是卡片标题）、显示顺序、版权状态、封面、字幕等；
- 在 **视频来源** 里切换成另一条已上传视频，或上传新视频替换；
- 改完仍然先点 **保存修改内容**，再填 **保存名称**，最后点 **上传媒体资源**。

视频分享没有“补充文章内容”的选项；如果需要文章，请去 **动态新闻内容** 新建动态新闻。

---

## 三、删除视频分享

列表里点 **删除**。视频分享只有视频，所以只有一种删除方式：

- 删除视频素材和这张卡片，官网上的卡片一起消失；
- 如果这个视频素材还被其他内容引用，素材会保留，但这张卡片会消失。

删除后不可恢复。

---

## 四、常见报错对照

| 提示文案 | 原因 | 怎么处理 |
| --- | --- | --- |
| 仅支持 MP4 或 WebM 视频文件 | 传了 mov/avi 等，或文件真实格式与扩展名不一致 | 转成 mp4 或 webm |
| 视频文件超过 500 MB 的上限 | 文件太大 | 压缩或降码率 |
| 请填写视频卡片标题 | 标题为空 | 填一个卡片标题 |
| 先点击“保存修改内容”，才能上传媒体资源 | 跳过第一步 | 先点“保存修改内容” |
| 请填写保存名称，再上传媒体资源 | 保存名称为空 | 填保存名称 |
| 这个视频已经属于另一张视频分享卡片 | 选了已被其他卡片占用的视频 | 换一条视频，或去修改原卡片 |
| 视频素材仍被其他内容引用，未删除 | 其他内容还在引用 | 先解除其他引用 |
| 没有找到支持的视频格式和 MIME 类型 | 浏览器无法解码这个视频 | 重新导出为 H.264 + AAC 的 MP4，或换一个视频 |

## 一页速查

```
视频新闻 → 视频分享内容 → 新增视频分享
  来源：电脑文件 / 系统已上传媒体
  使用范围 = 视频新闻
  展示位置 = 视频分享列表
  （页面/段落自动填 news / video-sharing）
  勾选“发布后允许此位置使用”
  → 保存修改内容
  → 填保存名称
  → 上传媒体资源
  → 看到绿色“媒体资源已上传”提示

修改：选卡片 → 修改 → 可换视频 → 保存修改内容 → 填名称 → 上传媒体资源
删除：选卡片 → 删除 → 确认删除（视频和卡片一起消失）

动态新闻：视频新闻 → 动态新闻内容 → 新建草稿 → 文章 + 图片（不传视频）
```

媒体素材上传后直接可用，不需要审核、送审或发布队列。
