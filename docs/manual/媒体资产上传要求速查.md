# 媒体资产上传要求

> 上传报 **400** 时对照此表。**先看界面上的错误提示**——它比浏览器的网络错误有用得多。
>
> 媒体素材（含视频）**上传即发布，不再需要送审或审批**。

---

## 现在只有 4 件事会拦住你

尺寸、文件大小、视频时长**都不再拦截**（2026-10-11 放宽）。
运营手里常常只有一种素材，卡尺寸等于没法上线。画质不够会在界面上**提示**，但不会挡住上传。

真正会拦住上传的只剩这四条 —— 因为**缺了页面会直接坏掉**，不是画质下降：

| 会拦住的 | 说明 | 怎么解决 |
| --- | --- | --- |
| **位置与类型不匹配** | 选了「视频」位置却传图片（或反过来） | 换成匹配的文件类型 |
| **该位置要求文稿** | 服务教学、先进制造类视频位要求字幕或文字稿 | 填写「字幕或文字稿」 |
| **使用范围没选** | 决定素材用于哪个官网栏目 | 下拉里选一个 |
| **自动播放/静音要求** | 首屏类视频位要求自动播放并静音 | 勾选「自动播放」和「默认静音」 |

封面（海报）是可选项：没设置时官网先显示视频首帧，之后可以在素材清单里补。

## 关于竖屏视频

**现在可以传了。** 之前要求宽度 ≥ 1280，常见的 1080×1920 竖屏会被卡住，已放宽。

| 分辨率 | 现在 |
| --- | --- |
| 1920×1080 横屏 | ✅ |
| 1280×720 横屏 | ✅ |
| **1080×1920 竖屏** | ✅ **可以传** |
| 720×1280 小竖屏 | ✅ 可以传 |

**建议**：竖屏视频宽度尽量 ≥ 1080，否则在 16:9 播放器里实际画面会比较小。
界面上会提示推荐尺寸，看到提示不代表失败。

## 表单必填项

| 字段 | 说明 |
| --- | --- |
| **使用范围** | 网站主页 / 产品展示 / 先进制造 / 视频新闻 / 关于瑞钧 / 服务支持 |
| **展示位置** | 决定了推荐尺寸和类型 |
| **版权状态** | 必选。这是**合规要求**，请如实填写 |
| **媒体类型** | 图片 / 视频 / 文档，需与实际文件一致 |
| **启用** | 勾选 |

## 上传被拒时的自查

- [ ] 界面上的**错误提示**写了什么？（最直接的线索）
- [ ] 「展示位置」和文件类型匹配吗？
- [ ] 视频提供封面图了吗？
- [ ] 「使用范围」「版权状态」都选了吗？

## 一条经验

**先看界面提示，不要看浏览器的网络错误。** 浏览器只说"400"，
界面会说明具体原因——那才是能直接行动的信息。
