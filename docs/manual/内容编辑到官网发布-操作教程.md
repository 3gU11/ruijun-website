# 内容编辑到官网发布 · 操作教程

> 面向：日常维护官网内容的人（运营 / 行政 / 市场）
> 适用版本：瑞钧官网 + CMS（Directus）内容工作流
> 最后验证：2026-10-13，用真实浏览器完整走通 10 步流程，含最终落地官网

---

## 一、能做到吗

**能。** 从「在后台改一句话」到「官网上看到这句话」，整条链路已经打通并验证过。

不过它**不是改完立刻生效**——内容要走一套审核流程，这是有意的设计（见文末附录）。
走完大约需要 **2～3 分钟**，其中大部分是等待官网缓存刷新。

---

## 二、先理解一件事：内容是有"状态"的

后台每一条内容都处于某个状态，状态只能沿着下面这条路往前走：

```
  草稿 ──提交审核──▶ 审核中 ──批准──▶ 待发布 ──正式发布──▶ 已发布
   ▲                  │                                      │
   │                  └──退回修改──┐                          │
   │                               ▼                          │
   └──────────恢复草稿──────── 已下线 ◀──────下线内容──────────┘
```

**三条规则，理解了就不会卡住：**

1. **不能跳步。** 草稿不能直接发布，必须先经过「审核中 → 待发布」。
2. **已发布的内容不能直接改。** 想改，必须先「下线 → 恢复草稿」，改完再走一遍审核。
3. **每一步都有按钮，走完一步再走下一步。** 看不到按钮，通常是上一步没完成。

## 三、准备工作

1. **服务已启动。** 双击项目根目录的 `启动CMS官网维修系统.bat`，等它打印出地址即可。
2. **打开后台。** 浏览器访问：
   - 本机：`http://127.0.0.1:8055/admin`
   - 局域网内其他电脑：`http://<主机IP>:8055/admin`（启动脚本会打印这个地址）
3. **登录。** 用你的 CMS 账号（目前是管理员账号）。

### 两个工作台的入口

登录后，操作都在**两个不同的工作台**里完成，别找错地方：

| 工作台 | 怎么进 | 干什么 |
|---|---|---|
| **内容编辑工作台** | 左侧边栏的**铅笔图标**（鼠标悬停显示"内容编辑工作台"） | 改内容、送审、审核 |
| **内容发布队列** | 左侧边栏的 **"内容发布队列"** 条目 | 正式发布、下线、归档 |

> 两个工作台都在后台内部，不需要记网址。如果侧边栏看不到铅笔图标，说明账号权限不够，找管理员开通。

## 四、完整流程：修改一个已经发布的页面

这是最常见的场景。以「服务支持」页为例，**一共 6 步**。

### 第 1 步 · 把页面从官网下线

已发布的页面是锁住的，先要把它"拿回来"。**这一步必须做，不能跳过。**

1. 回到后台主界面，打开 **「内容发布队列」**
2. 点 **「已发布」** 分类
3. 在列表里找到 **「服务支持」**，点它
4. 点 **「下线内容」**

**成功的样子：** 状态从「已发布」变成「已下线」。

> **为什么不能直接改？** 「恢复草稿」列表里**只有已下线或退回的内容**。
> 已发布的页面不在那里——直接去「恢复草稿」会看到空列表，提示「当前账号没有可恢复的内容」。

### 第 2 步 · 恢复成可编辑的草稿

1. 进入**内容编辑工作台**（左侧铅笔图标）
2. 点顶部导航的 **「内容送审」**
3. 在左侧小标签里点 **「恢复草稿」**
4. 在左边列表里找到 **「服务支持」**，点它
5. 右侧会显示这条记录，点 **「恢复为草稿」**

**成功的样子：** 记录状态从「已下线」变成「草稿」。

> **提示**：「提交审核」和「恢复草稿」两个标签显示的是**不同队列**：
> 「提交审核」= 草稿，「恢复草稿」= 已下线/已退回。选错标签就什么都看不到。

### 第 3 步 · 改内容并保存

1. 点顶部导航的 **「服务支持」**（页面标签，不是"内容送审"）
2. 中间会出现这个页面的区块列表，点你要改的区块，例如 **「服务支持首屏」**
3. 在右侧表单里改文字。比如找到 **「正文」** 输入框，修改里面的文字
4. 改完点最下面的 **「保存页面草稿」**

**成功的样子：** 页面顶部出现绿字提示 **「页面草稿已保存，并已进入内容版本审计。」**

> **注意**：只改不保存，等于没改。一定要点「保存页面草稿」。
> 如果提示里出现红字（例如"存在未登记的素材"），说明有东西没配好，先解决它再保存。
>
> **也可以不改表单，改成在画布上直接点着改**——见下面第五节的「画布方式修改」。

### 第 4 步 · 提交审核

1. 回到 **「内容送审」**
2. 这次点左侧的 **「提交审核」** 小标签
3. 在列表里找到刚才那条 **「服务支持」**，点它
4. 可以在「提交说明」里写一句改了什么（选填，但建议写）
5. 点 **「提交审核」**

**成功的样子：** 状态变成「审核中」。

> 提交后内容会**冻结**，这一步之后就不能再改了。想改要等审核退回，或走完整流程重新来过。

### 第 5 步 · 审核批准

1. 打开 **「高级设置」**（顶部导航右侧的展开按钮）
2. 点 **「审核队列」**
3. 在左边列表里点 **「服务支持」**
4. 点 **「批准进入待发布」**

**成功的样子：** 状态变成「待发布」。

> 这个页面只有「退回修改」和「批准进入待发布」两个按钮。**它不会发布**——发布是下一步。

### 第 6 步 · 正式发布

1. 回到后台主界面，打开 **「内容发布队列」**
2. 在 **「待发布」** 分类里找到 **「服务支持」**，点它
3. 点 **「正式发布」**

**成功的样子：** 状态变成「已发布」。

### 然后 · 等官网刷新

**等约 30 秒**，然后刷新官网页面（`http://127.0.0.1:4175/service`），就能看到新内容。

> 官网有 30 秒缓存。**立刻刷新看不到是正常的**，不是失败。等半分钟再刷。

## 五、画布方式修改（所见即所得）

上面第 2 步是在**表单**里改。还有一种方式：**直接在官网画面上改**——画布里显示的就是真实官网页面，点哪儿改哪儿。

### 前提

和实时预览一样，**只对草稿开放**。已发布的内容画布是只读的，要先走第 1 步「恢复草稿」。

### 步骤

1. 按第 1～2 步做到：内容已是草稿，并且**选中了页面和区块**（例如「服务支持 / 服务支持首屏」）
2. 点 **「打开实时预览」** —— 画布出现，里面就是官网真实页面
3. **选工具**：要改文字点 **「文字」**，要换图片/视频点 **「媒体」**
   - ⚠️ 工具必须和要点的东西匹配。用「文字」去点图片，**不会有任何反应，也不报错**
4. **单击**要改的那段字 —— 右侧会弹出属性面板，顶部会显示选中的字段名（如 `body`）
5. **双击**同一段字 —— 它变成可直接编辑，**在画布上直接打字**
6. 改完点空白处（或面板外），然后点右上角 **「保存草稿」**
7. 回到表单方式走第 3 步「提交审核」继续发布流程

### 重要：不要点「编辑模式」按钮

打开实时预览时，**编辑模式已经自动开启了**（按钮会显示「编辑中」）。

如果你再点一下，它会被**关掉**（变成「编辑模式」），之后画布上点什么都不响应，也不会有任何提示。

> 判断方法：按钮显示 **「编辑中」= 可以编辑**；显示「编辑模式」= 已关闭，再点一下打开。

### 画布工具栏

| 按钮 | 作用 |
|---|---|
| 选择 / 文字 / 媒体 | 选元素类型，必须匹配 |
| 桌面 / 平板 / 手机 | 切换预览尺寸；**只有「桌面」能编辑**，另两个是只读预览 |
| 撤销 / 重做 | 回退画布上的改动 |
| 居中 / 适应窗口 | 画布显示位置 |
| 编辑模式 | 显示「编辑中」才是开启状态 |
| 保存草稿 | 把画布上的改动写回后台 |
| 取消 | 放弃未保存的改动 |
| 专注画布 | 画布铺满窗口 |
| ↻ | 重新连接实时预览（画面卡住时用） |

### 画布能改什么

画布上带字段标记的内容都能改，例如：

- 标题、副标题（`title`）
- 小标题（`kicker`）
- 说明文字（`description`）
- 正文（`body`）
- 按钮文字（`label`）
- 列表项文字（`items.0.label`、`items.1.label`…）

### 改完一定要保存

画布上的改动**不会自动保存**。改完必须点 **「保存草稿」**，否则刷新就没了。

## 六、其他常见场景

### 场景 B：改一个还是草稿状态的内容

跳过第 1、2 步，直接从**第 3 步**开始（改内容 → 保存 → 送审 → 批准 → 发布）。

### 场景 C：只想把某个页面从官网撤下来

**内容发布队列** → **「已发布」** 分类 → 选中该页面 → 点 **「下线内容」**。

下线后官网立刻不再显示该页的 CMS 内容（会退回静态兜底文案）。之后想重新上线，从第 1 步走完整流程。

### 场景 D：改完后悔了，想撤回

- **还在草稿阶段**：直接重新编辑、重新保存即可。
- **已经提交审核**：让审核人点「退回修改」，内容会回到可编辑状态。
- **已经发布了**：走场景 C 下线，再走第 1 步恢复草稿重新改。

## 七、容易卡住的地方

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 「恢复草稿」列表是空的 | 该内容还是**已发布**状态——这个队列只装已下线/已退回的内容 | 先去「内容发布队列 → 已发布 → 下线内容」，再回来（见第 1 步） |
| 「提交审核」列表是空的 | 没有草稿 | 先在第 3 步保存一次草稿 |
| 保存时红字提示"存在未登记的素材" | 区块引用了未发布的图片/视频 | 先到「媒体资产」把素材走完发布流程，再回来保存 |
| 页面编辑器里输入框是灰的、不能改 | 内容不是草稿状态 | 回到第 1、2 步：先下线，再恢复草稿 |
| 发布时提示不满足条件 | 有前置检查没过（如空导航、未发布素材） | 按提示补全后再发布 |
| 官网看不到改动 | 30 秒缓存 | 等半分钟再刷新 |
| 侧边栏找不到铅笔图标 | 账号权限不足 | 找管理员确认账号角色 |

## 八、出问题了怎么办

1. **先看提示。** 工作台顶部会显示绿字（成功）或红字（失败原因），红字通常直接说明问题。
2. **确认状态。** 卡住时先看当前状态是什么——大多数"点不动"都是因为状态不对。
3. **不要反复点。** 提交类按钮点一次后请等待提示，重复点击可能造成重复提交。
4. **找人。** 如果提示看不懂或状态异常，把**截图 + 页面名称 + 当时状态**发给技术人员。

## 附录：为什么要这么多步骤

这套流程不是故意麻烦，它解决三个真实问题：

**1. 防止误改直接影响官网。** 内容编辑改的是"草稿"，草稿对访客完全不可见。
只有走完审核并发布，访客才能看到。改错了不会当场出事。

**2. 让改动可追溯。** 每次保存都会记录"谁在什么时候改了什么"（内容版本审计）。
出问题能查到是哪次改动引起的。

**3. 发布前有自动检查。** 正式发布时服务端会重新校验内容完整性、
图片素材是否已发布、发布前置条件是否满足。不满足就拒绝发布，而不是发一个坏页面出去。

**关于"已发布不能直接改"：** 因为已发布内容的任何直接修改都会立刻暴露给访客，
且绕过了审核记录。所以必须先下线——这是为了保护官网，不是限制你。

## 技术备注（给技术人员）

- 完整链路：`draft → review → scheduled → published`，反向 `published → unpublished → draft`
- 角色：管理员（`system_admin`）可独立走完全程；内容编辑（`content_editor`）可编辑与送审
- 发布动作由 `content-publication-queue-workbench` 承担；送审/审核在 `content-editor-workbench`
- 官网公开内容缓存约 30 秒（`website` 侧 BFF 层）
- 端到端自动验证脚本：`cms/scripts/acceptance/verify-cms-to-nuxt-e2e.mjs`
  - 默认模式：编辑 + 管理员（职责分离）
  - `--admin-only`：仅管理员账号（单账号部署）
