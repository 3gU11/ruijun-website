# CMS 企业资料受控媒体编辑说明

## 适用范围

内容编辑台“企业资料”中的“资质证书”和“制造证据”现可直接关联受控媒体：

- 资质证书使用 `qualification` 范围的已发布媒体资产。
- 制造证据使用 `manufacturing` 范围的已发布媒体资产。

## 使用流程

1. 在“媒体资产”中上传并登记候选素材，补全版权状态和来源说明。
2. 由对应的品牌或技术审核人员审核，发布人员发布该素材。
3. 回到企业资料草稿，选择对应范围的已发布素材并添加后保存。

编辑台只展示 `status=published` 且 `publication_state=published` 的素材。当前引用若不在可选列表中会保留并显示为“尚未通过此选择器验证”，不会因编辑其他字段而被静默删除。

## 发布边界

企业资料保存仍只是草稿更新。制造证据和资质证书进入审核、排期或发布时，服务端会再次检查所有 `media_asset_id` 是否为已发布状态；直接填写草稿素材 ID 或未授权文件无法绕过审核。
