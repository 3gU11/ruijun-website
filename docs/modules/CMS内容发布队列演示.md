# CMS 内容发布队列演示

## 入口

登录 CMS 后打开：`/admin/ruijun-content-publication-queue-workbench`

## 可处理内容

发布人员可以在同一工作台查看三类内容：

- `待发布`：技术审核或品牌审核已通过、等待正式发布的记录。
- `已发布`：当前已经对官网公开的记录，可执行受控下线。
- `已下线`：已经撤回公开、可以归档的记录。

每次操作都通过当前 Directus 登录会话提交，仅发送目标状态和可选说明，不会在生命周期流转时修改正文、参数或媒体引用。服务端会再次校验角色范围、状态转换、内容完整性和受控媒体；校验失败时记录保持原状态。

## 产品发布边界

产品系列、产品型号和产品参数不在通用队列中。它们必须进入“产品统一发布”工作台，由同一份产品快照发布，确保官网产品列表、详情和对比使用相同版本。

## 演示顺序

1. 使用发布人员账号打开“待发布”，选择一条已排期记录。
2. 填写发布说明并执行“正式发布”。
3. 在“已发布”中确认记录进入公开状态，再执行“下线内容”。
4. 在“已下线”中确认记录保留审计轨迹后执行归档。
5. 打开“内容版本”检查发布、下线和归档产生的版本审计；需要恢复时只能生成新的未发布草稿。

CMS 本地演示不代表生产环境已完成 MySQL、对象存储、HTTPS、备份或正式域名部署。
