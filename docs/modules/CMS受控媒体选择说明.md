# CMS 受控媒体选择说明

## 2026-09-23：实时画布编辑补充（优先于下方历史说明）

“仅已发布素材可选”的旧说明不再适用于所有实时画布选择器。已登录编辑者可使用匹配用途、页面、区块和媒体类型的启用草稿素材进行内部预览；公开读取和发布校验仍保持原有边界。候选是否存在以当前账号的选择器结果为准，不以本文演示数据为准。

1. 进入对应栏目及草稿，打开实时预览，开启编辑模式并选择媒体工具。
2. 点击目标媒体。核对属性面板的集合、记录 ID 和字段路径；独立首页理由使用 `homepage_sections`，页面段落使用 `pages`，同名区块不代表同一条数据。
3. 从媒体替换中选择候选。没有候选时核查素材页面、区块、用途、类型、启用状态和草稿预览权限，不直接填写外链或文件 URL。
4. 确认预览实际加载新图片或播放新视频，保存草稿，再完整重新打开工作台与预览确认。仅地址变化不能证明素材成功解码。
5. “只读/待媒体”表示缺少合格绑定；先在对应区块添加受管媒体。“待建模”表示尚无受控字段。固定 Logo、纹理和动画装饰不进入普通媒体替换。

首页三大理由的用途分别为 `home.reason.background`、`home.reason.machine`、`home.reason.icon`，对应角色 `background`、`foreground`、`icon`，不能互换。首页视频海报和结束静帧共用图片用途 `home.hero.poster`，但区块媒体角色分别为 `poster`、`end-frame`。在编辑模式入口分别选择，避免修改到另一槽位。

关于页机器前景在当前桌面公开布局隐藏；编辑模式提供标注“当前桌面布局隐藏”的素材预览入口。替换该素材不会改变桌面官网原有布局。

以下保留早期发布流程说明；“当前演示数据”是历史快照，不能作为实时资产数量或可用性判断。

## 编辑台范围

内容编辑工作台会在以下字段提供受控媒体选择器：

- 文章与视频的 `cover_asset`：仅显示已发布且 `usage_scope=article` 的媒体资产。
- 服务资料的 `asset`：仅显示已发布且 `usage_scope=service` 的媒体资产。
- 产品系列的 `cover_asset`：仅显示已发布且 `usage_scope=product` 的媒体资产。
- 产品型号的 `media`：仅显示已发布且 `usage_scope=product` 的媒体资产，并以受控引用数组保存。
- 全站设置的 `brand.logo_asset`：仅显示已发布且 `usage_scope=brand` 的媒体资产；服务端会在送审和发布时校验该嵌套引用。

选择器通过当前 Directus 登录会话读取 `media_assets`，不在浏览器保存服务账号、管理令牌或文件上传凭据。

## 审核边界

- 选择器只显示 `status=published` 且 `publication_state=published` 的资产。
- 没有合格资产时显示空状态，并引导编辑人员进入原生媒体流程完成上传、登记、版权确认、审核与发布。
- 历史手工录入的资产引用不会被自动修改；如果它不在已发布候选中，界面会明确标记为“尚未通过选择器核验”。
- 文章、服务资料和媒体资产仍由既有服务端状态机进行最终校验，选择器不会送审、发布或绕过版权和媒体治理。

## 当前演示数据

当前本地 CMS 没有已发布 `media_assets`，因此所有选择器均为受控空状态。这是预期行为，不代表媒体上传、版权确认或官网发布已完成。
