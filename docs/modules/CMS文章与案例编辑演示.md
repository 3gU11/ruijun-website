# CMS 文章与案例编辑演示

## 演示入口

- 内容编辑工作台：`/admin/ruijun-content-editor-workbench`
- 工作台标签：`文章与案例`
- 本地演示地址：`http://172.21.8.158:8055/admin/ruijun-content-editor-workbench`

## 文章与视频草稿

“新闻与文章”子标签支持创建和维护未发布草稿，字段包括：

- slug、分类、标题、摘要、正文和可选视频地址。
- 受控封面媒体引用。
- SEO 标题、关键词和描述。
- 来源文档或来源地址。

正文和视频地址可二选一；发布前仍由服务端检查摘要、封面、SEO、来源和发布状态。封面媒体必须在 Directus 原生详情中关联并按 `media_assets` 治理流程审核。

## 客户案例草稿

“客户案例”子标签支持维护案例标识、行业、材料、厚度、关联型号、工艺过程、结果、来源和客户授权状态。

案例在满足所有业务字段、来源和客户授权前不能通过发布就绪检查。编辑台不会把“待审核”授权状态变成已确认授权，也不会提供送审或发布操作。

## 验证

本地浏览器已验证：空列表加载、文章草稿创建、标题更新和内容版本审计。验证使用 `cms-editor-*` 唯一 slug 创建临时未发布草稿，并在验证结束后按精确 slug 与草稿状态清理。CMS 全量自动化测试和运行自检均通过。
