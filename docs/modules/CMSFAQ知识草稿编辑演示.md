# CMS FAQ 知识草稿编辑演示

## 入口

在内容编辑工作台中打开“FAQ 知识”页签。该页只面向已导入的 FAQ 草稿，供内容与售后技术人员补齐审核所需信息。

## 可维护内容

- 问题标题、分类、适用型号、错误代码和故障现象。
- 排障步骤或保留的原始知识内容。
- 风险等级、可见范围、使用渠道、知识版本和技术审核责任人。
- 高风险知识的安全前置条件与人工升级说明。
- 已发布、用途为 `knowledge` 的受控图片或附件。

来源键和来源文档为只读，避免导入器失去幂等对应关系。已有但未通过选择器核验的媒体引用会保留并标记；送审与发布时仍由服务端校验所有媒体已发布。

## 工作流边界

- 本页只保存 `draft`、`rejected` 或 `unpublished` 记录，并由现有服务端工作流写入内容版本审计。
- 不提供送审、审核批准、公开发布或 Dify 同步操作。
- 高风险知识缺少安全前置条件或人工升级说明时不能保存；所有知识缺少题目、分类、版本、责任人或排障内容时，浏览器与服务端审核规则都会阻止其进入后续审核。
- 把可见范围改为“公开候选”仍只是草稿标记。只有审核、排期、发布流程完整通过后才能成为公开知识。

## 当前演示数据

本地 CMS 现有 235 条从 FAQ 归档导入的内部草稿，其中大量内容仍需要售后技术人员逐条确认风险等级、安全边界和审核责任人。它们未公开，也未同步至 Dify。
