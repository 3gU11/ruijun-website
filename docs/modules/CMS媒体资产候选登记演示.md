# CMS 媒体资产候选登记演示

## 入口

内容编辑台的“媒体资产”页签用于登记官网可使用的图片、视频和 PDF 候选素材。

## 编辑流程

1. 选择文件，并填写使用范围、替代文本、版权状态及来源/授权说明。
2. 点击“上传并登记候选素材”。系统先保存文件，再以私有草稿创建 `media_assets` 记录。
3. 由对应范围的技术审核或品牌审核角色提交审核意见并批准。
4. 发布人员发布素材后，素材才会进入产品、服务资料、文章等内容模块的受控素材选择器。

## 约束

- 编辑人员无法在此页直接发布素材。
- 支持 JPG、PNG、WebP、AVIF、MP4、WebM、PDF；浏览器会先检查类型和大小，服务端会再次校验实际文件元数据。
- 上传文件和 `media_assets` 元数据必须一致。文件扩展名与 MIME 类型不一致、超出大小上限或未填使用范围会被拒绝。
- 若候选登记失败，编辑台会尝试清理本次刚上传的文件；任何失败都不会改变已发布官网内容。
- 已发布的素材仍需经既有内容版本、审核和发布工作流处理，不能通过直接填写文件 ID 绕过审核。

## 演示边界

本地演示使用 Directus 的本地文件存储。生产环境接入对象存储、病毒扫描、版权凭证留档和素材到期提醒，属于上线部署阶段，不在当前 Windows 演示范围内。
## 候选预览

“媒体资产”列表会在打开该标签后，为图片候选加载受当前 Directus 登录会话保护的缩略图。缩略图通过认证 API 请求取得，浏览器仅在内存中创建临时 Blob URL；关闭工作台或刷新候选列表时会回收该 URL。

图片草稿不会因此变成公开文件，也不会生成携带访问令牌的外链。视频和 PDF 继续显示文件类型标识，详情仍可通过原生内容页查看。
