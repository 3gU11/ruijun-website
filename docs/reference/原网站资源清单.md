## 2. 已获取的制造能力信息

- 旧站称具备年产上万台套中走丝线切割机床能力。

- 钣金车间包含智能下料、成型、焊接与连接及静电喷涂产线。

- 制造体系被组织为：研发实验、制造加工、主要部件、整机装配、放电控制、操控系统、精密检测。

需要补证：厂区面积、设备数量、产能、产线数量、MES 覆盖范围，以及“全产业链制造”的准确边界。
