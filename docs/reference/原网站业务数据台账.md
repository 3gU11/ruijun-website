## 6. 导入与审核规则

1. 为每个来源文件记录 `source_url`、`source_title`、`source_captured_at`、`source_file_version`、`reviewer`、`reviewed_at` 和 `evidence_attachment`。
2. `ProductParameter` 需要单位、测试条件、适用型号、原始文件页码和审核状态；缺少任一项时只可保存为草稿。
3. 客户/供应商 Logo、证书图片、工厂/客户现场照片均需授权状态；原站可访问不代表新站自动具有重新发布权限。
4. 服务网点和联系人应以有效期管理。个人手机号、个人邮箱、厂商口令、设备内部参数和未审查图纸不得进入公开内容 API 或 Dify 知识库。
5. 公开下载资料应上传至受控对象存储，采用稳定文件 ID 与版本号，不能依赖旧站 `picfile` 外链。
