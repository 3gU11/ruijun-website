# NANFU-inspired interaction DNA

source: https://www.nanfu.global/
captured: 2026-07-29 at 1440 x 900
scope: extract interaction and composition principles for the RuiJun industrial website; no NANFU branding, copy or media is reused.

## Observed structure

- The opening visual owns the full viewport and carries one dominant product object, one short claim and one action.
- Wheel input first advances the opening media instead of immediately leaving the viewport.
- During the handoff, the dark opening stage progressively contracts into a left-side media frame while the next section's white canvas is revealed.
- The right-side heading appears before its supporting reasons, so the section has its own internal lifecycle.
- The header starts as a floating dark capsule and then stretches into a full-width fixed bar.
- Later stories use full-screen sections and horizontal progression rather than a long stack of ordinary content blocks.

## Visual tokens

- Canvas: near-black `#050506` alternating with cool white `#f3f3f1`.
- Accent: one saturated red for active navigation, progress and commands.
- Type: compact sans-serif display headings, restrained supporting copy and low-contrast evidence notes.
- Composition: one dominant media region plus one focused text region; generous unframed whitespace.
- Corners: the source uses rounded media frames; RuiJun keeps the established restrained `5px` radius from its PSD system.
- Navigation: fixed translucent black surface, then a full-width top bar after the hero.

## Motion tokens

- Source behavior: scroll-linked media progression, stage contraction, delayed content reveal and pinned horizontal sequences.
- RuiJun implementation: GSAP `Observer` captures desktop wheel/touch intent; `ScrollToPlugin` performs damped full-screen movement.
- Hero handoff: a fixed shared stage animates from the full viewport into `.intro-machine-wrap`; its machine image changes scale and position inside the same timeline.
- Background handoff: the hero raster fades out as the shared stage reaches the solid-black second-screen frame.
- Intro lifecycle: heading first, then three reason rows on separate gestures.
- Reason transition: scenes are stacked in one viewport; the current scene stays fixed while the next full-screen scene wipes in from the right as a higher layer, creating a crisp split frame at mid-progress.
- Reverse reason transition: the current upper layer moves back to the right and reveals the previous scene underneath.
- Horizontal lifecycle: the three cover-wipe reasons and history phases must finish before vertical navigation resumes.
- History reference: NANFU keeps a complete dotted trajectory visible, uses a large low-contrast display title, and lets a strong red directional marker anchor the horizontal motion while milestones pass through the viewport.
- RuiJun history adaptation: the opening state places a large gray title on the right and a red progress arrow at the far-left content margin. The arrow travels through the title and reveals each line to dark charcoal; both then yield to six large, staggered floating milestones moving horizontally without an axis, connector lines or node dots.
- Reduced motion/mobile: no forced Observer navigation; native vertical and horizontal scrolling remain available.

## Local mapping

- Floating/full-width navigation -> `.site-header` and `.site-header.is-wide`.
- Full-screen rows -> `.lifecycle-panel`.
- Shared hero stage -> `.machine-morph-overlay`, `runMachineMorph()`.
- Progressive reason copy -> `setIntroRevealStage()`.
- Horizontal reasons/history -> `setReasonSlide()` and continuous `setHistoryProgress()`.
- Thin edge progress -> `.immersive-indicator`.
