## 四、本次测试发现的问题（已修正）

### 「恢复草稿」队列不含已发布内容

**发现**：页面是 `published` 时，直接进「内容送审 → 恢复草稿」，列表是**空的**，提示「当前账号没有可恢复的内容」。

**原因**：该队列的取数条件是 `status IN (rejected, unpublished)`——**只装已下线或退回的内容，不装已发布的**。

**影响**：原操作教程把「恢复草稿」写成了修改已发布内容的第一步，**这一步实际做不到**，用户会卡在空列表上。

**正确顺序**（已修正教程）：

```
修改已发布的内容：
  ① 内容发布队列 → 已发布 → 选中 → 下线内容      （published → unpublished）
  ② 内容编辑工作台 → 内容送审 → 恢复草稿 → 恢复为草稿 （unpublished → draft）
  ③ 改内容（表单或画布）
  ④ 内容送审 → 提交审核
  ⑤ 高级设置 → 审核队列 → 批准进入待发布
  ⑥ 内容发布队列 → 待发布 → 正式发布
```

## 六、画布编辑的三个易错点（实测确认）

1. **打开实时预览时，编辑模式已自动开启**（按钮显示「编辑中」）。
   再点那个按钮会**关掉**它，之后画布上点什么都不响应，且无任何报错。
2. **工具必须匹配元素类型**：改文字用「文字」，换图用「媒体」。不匹配时静默忽略。
3. **单击 = 选中，双击 = 打开编辑器**。只单击不会进入编辑态。
