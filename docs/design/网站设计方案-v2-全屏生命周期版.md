# 瑞钧智科官网设计方案 v2

方案名称：**瑞钧中走丝 · Precision in Motion**  
主依据：[新网站建设方案](../prd/新网站建设方案.docx)  参考依据：原网站设计方案（历史资料，当前目录未收录）、NANFU Global Technology 页面交互研究

## 0. 方案定位

本版本不推翻 DOCX 中的六大页面规划，而是将其从“静态页面效果稿”升级为可落地的官网体验方案：

- 主页、产品展示、先进制造、新闻媒体、关于瑞钧、服务支持保留为一级页面。
- 每个一级页面由多个全屏内容段组成，每段承担一个明确任务。
- 桌面端采用滚轮/触控板接管式段落切换，每次手势进入下一段或上一段。
- 每个段落拥有自己的生命周期：进入、停留、离开三个状态，动画由滚动进度驱动。
- 页面切换采用阻尼缓动，不使用生硬的瞬移，也不允许快速滚轮跳过大量内容。
- 移动端降级为自然触摸滚动，保留段落进入动画，不接管系统滚动。
- 官网仍然只负责品牌展示、产品说明、内容引导和线索提交；维修工单、保修状态等继续由独立售后系统负责。

参考官网最值得借鉴的是“段落叙事方式”，不是颜色、文案或电池行业内容。瑞钧应使用自己的机床、加工、工厂、检测和服务素材完成品牌表达。

## 1. 设计目标

### 1.1 用户目标

工业客户进入官网后，应在 30-60 秒内完成以下判断：

1. 瑞钧是谁，主营什么设备。
2. 瑞钧适合哪些工件和加工任务。
3. 六个产品分类之间如何选择。
4. 瑞钧是否拥有真实制造、检测和交付能力。
5. 需要维修、资料或选型时应该从哪里进入。

### 1.2 品牌目标

将 DOCX 中的“行业领先、先进制造、产品分类、企业历程、售后服务”转化为可验证的证据链：

```text
真实设备 → 加工结果 → 制造过程 → 企业连续性 → 服务网络 → 选型/咨询
```

避免把网站做成单纯的宣传片，也避免只把旧站图片平铺成图库。

### 1.3 视觉关键词

精密、稳定、工业可信、克制、可检查、持续运动。

建议延续 DOCX 形成的黑/白/红基础系统：

| 角色 | 建议 |
|---|---|
| 深色背景 | 首屏、技术证据、服务 Banner、页脚 |
| 白色背景 | 产品展示、制造流程、企业介绍、资料区域 |
| 瑞钧红 | CTA、关键数字、当前段落、时间线节点 |
| 中性灰 | 参数、辅助说明、未激活状态 |

## 3. 参考官网的交互方法

### 3.1 全屏段落模型

每个页面由多个 `.lifecycle-panel` 组成：

- 桌面端最小高度：`100svh`。
- 顶部固定导航不计入内容高度，段落滚动目标为 `panel.offsetTop - headerHeight`。
- 内容段不得把多个主题挤在同一屏；一个段落只回答一个问题。
- 内容超过一屏时，优先拆成多个段落，而不是让用户在一个段落内连续滚动很久。
- 产品详情的参数表和长文本可以在段落内部自然滚动，但不应影响一级段落切换。

### 3.2 滚轮/触控板生命周期

桌面端采用 Observer 风格的输入处理，不直接依赖浏览器原生 `scroll-snap`：

```text
wheel deltaY / trackpad gesture
        ↓
累计手势意图，达到阈值 70px
        ↓
判断 next / previous panel
        ↓
锁定输入 820ms
        ↓
阻尼滚动到目标段落
        ↓
触发 panel enter / active / leave
```

建议参数：

| 参数 | 建议值 | 说明 |
|---|---:|---|
| 滚轮触发阈值 | 70px | 避免触控板微小抖动误切换 |
| 段落切换时长 | 780-900ms | 形成明显但不过度的阻尼感 |
| 缓动曲线 | `1 - (1 - t)^4` | 快速启动、末端减速 |
| 输入锁定 | 动画期间锁定 | 防止一次连续滚轮跳过多个段落 |
| 键盘映射 | ↑/↓、PageUp/PageDown、空格 | 兼容键盘用户 |
| 触摸滑动 | 55px | 移动端使用轻量段落跳转或自然滚动 |

### 3.3 段落生命周期

每段至少有三个状态：

```text
before   内容轻微偏移，等待进入
active   标题、图片、数字和 CTA 按顺序出现
after    保持可读，不做强制隐藏
```

动画规则：

- 标题先进入，延迟约 80ms。
- 图片和核心数字随后进入，延迟约 160ms。
- 辅助文字和 CTA 延迟约 240ms。
- 单次动画 450-800ms，禁止无限循环的装饰动画。
- `prefers-reduced-motion: reduce` 时取消位移和自动视频，只保留透明度与状态变化。
- 关键数据始终使用 HTML，不把数字只做进图片。

### 3.4 页面进度指示

桌面端右侧显示小型段落指示器：

- 当前段落使用瑞钧红。
- 其他段落使用半透明白或灰。
- 点击可跳转到指定段落。
- 每个圆点必须有可读的 `aria-label`，不能只依赖视觉。
- 移动端隐藏，避免占用窄屏空间。

## 4. 首页设计

首页不是完整企业介绍，而是从品牌识别逐步进入产品和服务。

### Panel H1：10 秒视频首屏

对应 DOCX：`首页出视频（10秒）`。

- 视频只自动播放一次，不循环。
- 播放期间展示真实机床运行/加工画面。
- 播放结束后切换为静态终帧图，显示“了解更多”按钮。
- 静态图建议使用 DOCX 中的黑底机床画面，按钮进入产品展示。
- 首屏保留品牌、主营方向和 `获取选型` 入口，但不要压住静态图内的重要文案。
- 视频加载失败时直接显示静态图，不显示空黑块。

### Panel H2：三大理由

对应 DOCX：左侧机器，右侧三大选择理由。

布局：左 45% 真实设备图，右 55% 三条理由；中间或右侧保留 `了解更多` CTA。

三条理由建议使用可复核的表达：

1. 产品效率性能提升：必须补充测试条件或案例入口。
2. 30 年技术沉淀与先进制造：年份和主体关系上线前复核。
3. 行业领先品牌：销量排名、市场范围和统计口径必须取得依据。

禁止直接把未经确认的“销量第一”“累计用户”等数字作为永久文案。

### Panel H3：厂房/制造证据

对应 DOCX：厂房大楼图片和销量冠军信息。

- 使用新厂房 Banner，数字和结论叠加在 HTML 中。
- 页面先展示厂房全景，再以阻尼滚动进入生产线、装配和检测细节。
- 数字模块采用“数字 + 口径 + 证据入口”，不要只放大号数字。
- 未确认数字使用“制造能力持续升级”等定性表达。

### Panel H4：六大产品分类

对应 DOCX：产品图片页，六个产品分类。

- 桌面端 3×2 展板布局，使用真实产品图和清晰型号标签。
- 每个产品位是可点击区域，进入产品详情。
- 当前产品位显示型号、定位和一个核心特点，不塞入完整参数。
- 通过生命周期动画依次显现六个产品位，避免同时堆满视口。
- 对比功能放在产品中心，不在首页增加复杂筛选。

### Panel H5：企业历程

对应 DOCX：钼丝火花向右横向移动贯穿历程。

- 桌面端以横向时间线为主，滚轮向下时将垂直手势映射为时间线进度。
- 火花/钼丝动画只是状态提示，不能遮挡年份和事件文字。
- 首期建议节点：1997、2003、2006、2014/2016、2020、2025。
- 每个节点包含年份、技术/制造事件和可验证资料入口。
- 移动端改为纵向时间线，不强制横向滚动。

### Panel H6：页脚

左侧：电话、地址、邮箱、网站地址。  
右侧：产品、先进制造、关于瑞钧、服务支持、隐私与图纸数据说明。

## 5. 产品展示页

### P1：选择瑞钧三大理由

延续首页三大理由，但使用产品购买语境：效率、制造、服务。

### P2：六个产品分类

每个分类卡片至少包含：

- 型号名称。
- 适用工件/生产场景。
- 关键差异。
- 查看详情。
- 进入对比。

### P3：产品详情

采用 DOCX 指定的左右结构：

```text
左侧：型号选择 / 产品缩略图 / 系列导航
右侧：产品特点 / 适用场景 / CTA
下方：技术参数、单位、配置、下载资料
```

信息顺序：

1. 设备定位和适用工件。
2. 真实设备图片、视频和尺寸。
3. 关键参数摘要。
4. 完整技术参数表。
5. 加工案例与检测结果。
6. 标准配置与选配项。
7. 下载参数 PDF、申请打样、获取报价。

参数必须结构化存储，不能只把参数做成一张 JPG 长图。

## 6. 先进制造页

对应 DOCX 的八类制造内容，采用“厂房 Banner → 生产流程 → 证据图库”的段落顺序：

1. 新厂房大楼 Banner。
2. CNC 车间。
3. 钣金车间。
4. 装配车间。
5. 检测仪器。
6. 智能物料仓储。
7. 所有设备展示。
8. 认证证书展示。

每一段回答一个质量问题：

| 制造段 | 应回答的问题 |
|---|---|
| CNC | 零部件尺寸和一致性如何控制 |
| 钣金 | 结构、外观和批量一致性如何控制 |
| 装配 | 装配环境、调试和追溯如何控制 |
| 检测 | 精度、几何误差和试切如何验证 |
| 仓储 | 物料、批次和备件如何管理 |
| 核心设备 | 瑞钧使用什么设备保证制造能力 |
| 认证证书 | 哪些体系/证书已经取得，何时更新 |

## 7. 新闻媒体页

对应 DOCX：展会图片/视频快闪形成一张展会 Banner，下面分视频和新闻。

### N1：展会 Banner

- 多张展会图片采用短时交替或拖动进度切换。
- 不自动无限轮播；用户滚轮进入时完成一次有节奏的图片过渡。
- Banner 文字使用日期、展会名称和内容类别。

### N2：视频

视频卡片显示封面、播放按钮、标题、日期和分类。正式发布时视频由后台配置，播放失败显示封面和文字入口。

### N3：新闻

新闻卡片显示标题、日期、封面、摘要和详情入口。新闻按时间倒序，但可按展会、制造、技术、企业动态筛选。

## 8. 关于瑞钧页

对应 DOCX 的十项内容，建议分为四个生命周期段：

### A. 品牌与历史

- 产品 Banner 过渡到旧厂房。
- `Since 1997` 只在主体关系确认后发布。
- 企业文化和用户数量使用可验证数字。

### B. 企业与制造

- 企业简介。
- 厂房风貌图片欣赏。
- 认证证书、企业荣誉、专利展示。
- 证书和专利均支持编号、日期、下载或查看详情。

### C. 历程与合作

- 鼠标滚轮驱动的技术历程动画。
- 合作客户与供应商 Logo 墙，必须获得使用授权。
- 客户现场图片区，标记行业和加工场景，不展示未经授权的敏感信息。

### D. 数据真实性

旧方案中出现的“累计用户 20000+”“专利 79 件”等数字统一标记为 `待复核`，未经企业负责人确认不进入正式发布状态。

## 9. 服务支持页

对应 DOCX：自动穿丝组件 Banner、在线支持、服务网点和技术内容。

### S1：自动穿丝组件 Banner

- 使用自动穿丝组件或机床局部特写作为首屏。
- 主 CTA：在线支持。
- 点击后可以打开独立售后系统或在线支持弹层。
- 外部系统打开前明确提示“即将进入售后服务系统”。

### S2：全国服务网点

- 先按区域筛选，再按城市/网点查看。
- 每个网点显示企业名称、区域、服务范围和企业级联系方式。
- 负责人、个人手机号由后台维护，不写死在设计稿中。
- 地图仅作为辅助，不用复杂 3D 地球阻塞查询流程。

### S3：技术支持

八个入口对应 DOCX：

1. 我的维修申请。
2. 保修状态验核。
3. 服务流程与寄修。
4. 视频教学。
5. 技术文件下载。
6. 常见故障分析。
7. 日常保养与易损件。
8. 知识分享。

维修申请和保修状态进入独立售后系统；视频、文件、保养和知识分享由官网内容后台维护。

## 10. 后台与系统边界

### 官网内容后台

- 页面段落排序、标题、文案、CTA 和语言版本。
- 产品分类、型号、参数、配置、媒体和 PDF。
- 新闻、视频、展会、制造图库、证书、专利、历程和网点。
- 段落动画参数只允许有限配置：启用/禁用、延迟、媒体、主题，不开放任意脚本。
- SEO、OG 图片、定时发布、审核和历史版本。

### 独立售后系统

- 客户、设备序列号、保修期、维修工单、服务进度和备件。
- 官网只通过后台配置的 HTTPS 超链接引导。
- 未来如需统一登录或官网内展示工单摘要，再评估 OAuth/OIDC 或标准 API。
- 不共享售后数据库，不通过页面抓取售后状态。

## 11. 内容状态与上线规则

| 状态 | 处理方式 |
|---|---|
| 已确认 | 可进入正式页面和 SEO |
| 待复核 | 进入后台草稿，不进入公开发布 |
| 缺失 | 使用结构占位，禁止编造数字或承诺 |
| 已过期 | 下线或替换，保留历史版本 |

必须经过技术/销售/管理审核的内容：产品参数、加工结果、销量排名、用户数量、产能、证书、专利、服务时效和客户 Logo。

## 12. 响应式与无障碍

- 桌面端：全屏段落 + 滚轮阻尼 + 右侧段落指示器。
- 平板端：段落保持完整，减少输入接管，允许自然滚动。
- 移动端：自然触摸滚动，内容按纵向段落排列，不强制横向拖动。
- 所有段落有语义标题，图片有替代文本，进度点有 `aria-label`。
- 不使用只有颜色表达状态，当前段落同时通过文字、焦点或位置表达。
- `prefers-reduced-motion` 时关闭视差、自动视频和大幅位移。
- 键盘用户可以使用 Tab、方向键和 PageUp/PageDown 完成浏览。

## 13. 验收标准

### 交互验收

- 桌面端一次滚轮只切换一个内容段。
- 切换时有可感知阻尼，动画期间不会连续跳段。
- 进入段落后标题、媒体、数字和 CTA 按顺序出现。
- 视频首屏播放结束后停在静态终帧并显示 CTA。
- 产品分类可以进入详情，详情可以进入咨询。
- 外部售后入口可由后台配置，链接失效时仍有人工联系方式。

### 内容验收

- DOCX 六大一级页面全部有对应入口。
- 产品详情包含型号选择、特点和技术参数。
- 先进制造包含八类制造内容。
- 新闻页同时包含视频和新闻。
- 关于瑞钧包含历史、证书、荣誉、专利、合作与客户现场。
- 服务页包含网点、型号搜索和八类技术支持入口。

### 性能验收

- 首屏视频提供静态图 fallback。
- 大图和视频懒加载，不阻塞首屏文字。
- 段落动画使用 transform/opacity，避免持续触发布局计算。
- 移动端不接管系统滚动，不出现横向溢出。

## 14. 实施顺序

1. 先完成六页信息架构和全屏段落骨架。
2. 接入首屏视频终帧、产品六分类和真实制造图片。
3. 完成产品详情参数结构和资料下载入口。
4. 完成新闻视频、关于瑞钧和服务网点内容模型。
5. 接入 CMS 草稿/审核/发布流程。
6. 配置独立售后 HTTPS 入口。
7. 做桌面滚轮、触控板、键盘、移动触摸和减少动效模式验收。
