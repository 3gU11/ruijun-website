# 设计上下文

## 项目定位

建设苏州瑞钧智能科技有限公司的新一代品牌官网，面向中走丝线切割机床采购者。网站的首要任务不是展示抽象的“科技感”，而是帮助访客快速判断：瑞钧设备能否加工我的工件、精度和稳定性是否可信、哪款机型适合、厂家能否长期交付与服务。

## 项目目标

- 建立专业、可靠、具备自主制造能力的机床品牌形象。
- 将参数浏览转化为明确的选型、打样、询价或技术咨询行为。
- 用真实加工结果、检测依据和制造过程降低采购风险感。
- 中文站优先服务国内采购与售后需求，英文站承接海外采购和渠道合作；两站共用产品数据，但转化入口和服务信息分别配置。

## 目标用户

- 模具、精密零件、汽车零部件、五金及机械加工企业的负责人。
- 设备、工艺与生产部门的工程师和技术决策者。
- 负责设备比价、采购流程和供应商准入的采购人员。
- 寻找产品线、交付能力和技术支持的海外代理商与渠道伙伴。

## 用户核心任务

访客应在 30 秒内确认企业主营中走丝线切割机床，并在 3 次操作内完成以下任一任务：

1. 按加工需求找到适合的机型。
2. 查看关键参数、精度依据和真实加工案例。
3. 提交工件图纸申请打样或获取选型建议。
4. 联系销售、售后或渠道合作负责人。

## 采购决策逻辑

```mermaid
flowchart LR
    A[确认加工需求] --> B[验证加工能力]
    B --> C[筛选适用机型]
    C --> D[评估厂家实力]
    D --> E[咨询选型或申请打样]
```

页面结构应服从这条决策链，而不是围绕视觉动画组织内容。

## V1 范围

- 首页：价值说明、加工能力、机型入口、技术证据、案例、制造与服务、询盘转化。
- 产品中心：机型列表、筛选、对比与产品详情。
- 行业应用：按行业、材料、厚度和工件类型组织案例。
- 技术与工艺：加工原理、核心技术、精度控制与常见问题。
- 服务支持：售前选型、安装培训、耗材备件、售后响应和资料下载。
- 关于企业：工厂、质检、研发、认证、历程与全球业务。
- 联系与询盘：选型咨询、图纸打样、报价及渠道合作。
- 内容管理后台：页面内容、产品参数、案例、新闻视频、服务资料、网点和 SEO 信息的维护与发布。
- 系统集成基础：官网提供可配置的售后系统 HTTPS 引导入口；API 或单点登录仅作为未来可选升级。

## 内容约束

- 所有精度、粗糙度、效率、重复切割次数等数字必须标明测试条件或依据。
- 不使用无法证实的“国际领先”“最高精度”等绝对化表述。
- 产品主图、加工样件、控制系统、工厂与检测设备优先使用真实素材。
- 3D、视频和动效仅用于解释机床结构或加工过程，不能阻碍参数读取和询盘。
- 关键参数、联系方式和表单必须由语义化 HTML 呈现，不依赖 Canvas。
- 旧站信息按“已确认、旧站公开待复核、缺失”管理；待复核内容不能作为无条件事实上线。
- 旧站产品详情长图仅作为录入来源，新站必须将参数、配置和卖点转为结构化内容。

## 已知业务基础

- 企业公开名称：苏州瑞钧智能科技有限公司；英文正式写法待确认。
- 旧站显示企业始创于 1997 年，2003 年研发第一代中走丝机床。
- 现有产品体系包含灵动切割工作站、FR-XS (Auto)、FR-Y、FL-XS、FR (Pro)、FT-XS 和 FR-G 七个系列。
- 已形成自动穿丝、伺服闭环、瑞钧 3.0 控制系统、第四代放电系统、四轴螺距补偿等技术主题。
- 旧站展示昆山、常熟制造基地，以及 CNC、钣金、装配、检测和 MES 追溯流程。
- 国内服务网络按长三角、珠三角、浙江、华中、西南、西北、华北、山东和东北区域组织。
- 已有中文与英文网站，但产品参数主要以图片发布，需要重新结构化。

详细来源和核实状态见[原网站资源清单](../reference/原网站资源清单.md)。

## 成功标准

- 首屏 10 秒内可识别产品类别、核心能力和主要转化入口。
- 从首页到目标机型、案例或询盘最多 3 次操作。
- 产品列表支持按行程、承载、加工厚度等真实字段筛选；字段待产品资料确认。
- 详情页可完成参数查看、机型对比、资料下载和咨询。
- 桌面端 LCP 不高于 2.5 秒，移动端不高于 3.0 秒。
- Lighthouse Performance、Accessibility、SEO 均达到 90 分以上。
- 键盘操作、屏幕阅读器、减少动态效果和无 WebGL 环境均可完成核心任务。

## 非目标

- V1 不建设在线购买、支付或复杂经销商后台，也不在官网内部复制完整售后工单系统。
- 不将首页做成难以跳过的长篇 3D 展示。
- 不把所有机型堆在首屏，也不让访客只靠型号名称理解差异。
- 不虚构客户 Logo、测试报告、出口国家或售后承诺。

## 新增后台与系统集成需求

- 官网前端内容不得写死在页面代码中；产品、案例、新闻、视频、服务资料和网点应由后台维护。
- 后台至少支持草稿、预览、发布、下线、定时发布和历史版本回滚。
- 后台使用角色权限区分管理员、编辑、销售、技术和售后人员；发布操作保留审计记录。
- 官网前端通过公开 API 获取已发布内容，后台 API 不直接暴露管理权限。
- 官网只负责引导用户进入独立售后系统，不在官网内部实现维修、保修或工单业务。
- 售后入口使用后台可配置的 HTTPS 超链接；工单、保修和维修数据完全由售后系统负责。
- API、单点登录或状态回传不属于 V1 必需范围，只有出现统一登录或官网内展示状态的需求时再评估。
- 联系表单和图纸上传需要进入线索系统或邮件队列，并保留失败重试与人工兜底机制。

## 待确认信息

- 企业英文正式名称、品牌视觉规范及 Logo 源文件。
- 国内直销、区域网点和海外经销之间的线索分配规则。
- 七个系列是否均为当前在售产品，以及完整机型、参数字段和重点推荐顺序。
- 可公开的精度、粗糙度、效率数据及对应测试条件。
- 行业案例、客户授权、样件图片、检测报告和认证资料。
- 旧站披露的厂区面积、设备数量、产能、产线和销量数据口径。
- 各服务网点的营业状态、响应方式、备件与培训政策。

## 当前假设

- 首期以企业采购线索为主要转化目标，不直接在线成交。
- 用户通常先有材料、尺寸、精度或产能需求，再寻找对应机型。
- 旧站已有工厂、装配、检测和设备运行素材，能够取得其中部分原始高清文件与使用授权。
- 具体参数尚未提供，方案中仅定义信息结构，不填写虚构数字。

## 主要风险

- 若缺少有测试条件的性能数据，页面难以建立技术可信度。
- 机型命名若缺乏清晰规则，用户会难以比较和选型。
- 只有设备效果图、没有样件与检测证据，会让官网像产品画册而非采购工具。
- 表单字段过多会降低线索提交率；图纸上传必须明确格式、大小和隐私说明。
- 如果先用超链接接入售后，入口体验、登录状态和数据回传会割裂，后续迁移需要额外重做。
