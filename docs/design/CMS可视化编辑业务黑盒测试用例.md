# CMS 可视化编辑业务黑盒测试用例

版本：v2.0 ｜ 日期：2026-09-23 ｜ 使用人员：内容编辑、运营、业务验收人员

状态：已编写，尚未执行。本文替代上一版宽范围技术测试稿，作为本次业务验收用例。

## 一、测试目的

验证业务人员能否在页面上直接选择文字、图片、视频和列表，完成修改、查看效果、保存和再次打开确认。全程只使用浏览器页面，不需要编程，也不需要查看代码、接口、数据库或浏览器开发者工具。

页面范围：网站主页、产品展示、先进制造、视频新闻、关于瑞钧、服务支持。只测试这些页面的可视化编辑，不测试销售咨询提交、维修工单、FAQ 问答、系统部署或复杂审批流程。

“保存草稿”不等于“发布官网”。保存效果应在重新进入编辑页面和草稿预览中确认，不能以公开官网未变化判断草稿保存失败。

## 二、开始前准备

1. 由负责人提供可编辑账号、后台地址，以及专门用于测试的页面或内容。不要自行选择真实业务内容做删除试验。
2. 使用电脑浏览器登录后台，打开“内容编辑工作台”。测试前记录原来的文字、图片、顺序和位置，必要时截图。
3. 准备两张肉眼明显不同的图片，例如“测试图片A”和“测试图片B”，由负责人确认可以用于同一位置；准备两段不同视频及配套封面。
4. 准备两个不同产品型号、两条新闻，以及至少含三项的测试列表。记录其名称，操作时按名称选择。
5. 测试文字使用“可视化测试—用例编号”，方便发现是否改错了位置。
6. 每条用例做完后恢复原内容，再点击“保存草稿”，刷新检查。新建的专用测试内容按负责人要求清理。

页面说明：中间显示官网画面的区域称为“画布”；选中文字或图片后，旁边出现的输入区域称为“属性面板”。点击“编辑模式”后按钮可能显示“编辑中”，表示现在可以选中内容。

结果填写：

- **通过**：每一步均能完成，所有预期现象均符合。
- **失败**：具备账号、素材和测试内容，但操作或结果不符合预期。
- **阻塞**：缺账号、素材、测试内容，或规则未明确，暂时无法判断。
- **不适用**：负责人明确确认该位置不提供此能力，并记录原因。
- **未执行**：尚未操作。找不到承诺提供的按钮不能直接填“不适用”。

优先级：“必测”是本次核心验收；“常规”用于完整回归。所有初始结果均为未执行。
