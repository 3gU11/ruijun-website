## 1. 产品结论

本项目不是任意拖拽建站器，而是叠加在现有 Nuxt 官网上的“受控可视化编辑器”。编辑者在真实 Nuxt 画布中选择元素，顶部工具栏和右侧属性面板修改内容；模板只开放预先批准的字段和位置范围。

必须保持不变：Nuxt 原有布局、PSD 坐标、动画、路由、锚点、断点和响应式结构。CMS 只能改变内容数据及模板白名单内的展示参数，不能写入任意 HTML、CSS、JavaScript 或组件代码。

## 3. 目标与成功标准

### 3.1 P0 目标

1. 六页均可从同一个工作台按“页面 → 真实区块 → 元素”进入编辑。

## 5. 数据与绑定契约

```json
{
  "collection": "product_series",
  "itemId": "1",
  "sectionKey": "series-card",
  "fieldPath": "title"
}
```

- `collection` 和 `itemId` 必须来自 Directus 真实记录，禁止用数组下标或显示文本猜测。
- `sectionKey` 必须稳定，跨刷新不变；`fieldPath` 支持嵌套字段和媒体字段。
- fallback、PSD 静态层和未托管外链只读，并在诊断面板标注原因。
- 服务端保存前校验字段权限、类型、媒体规格、位置范围和工作流状态。

### 内容规则

- 动态新闻：标题、业务日期、封面、富文本正文、状态；点击展开图文详情。
- 视频分享：标题、业务日期、视频文件；默认取视频首帧，可人工替换封面。
- 新闻和视频分享每页最多 6 条，按业务日期倒序，超出分页。
- 产品、设备、证书、客户、合作品牌、办事处和里程碑不设“四张图”硬上限，支持新增、隐藏、排序；展示方式由模板决定。
- 首页与关于瑞钧共用里程碑主数据，禁止复制出两份可冲突记录。

## 6. 工作台交互与编辑边界

固定桌面布局：顶部工具栏、左侧页面/区块树、中间 Nuxt 画布、右侧属性面板。

- 顶部：页面切换、选择模式、文字/媒体属性、撤销、重做、缩放、保存草稿、预览、发布状态。
- 左侧：选择区块后画布自动定位并高亮；菜单不得覆盖画布或属性面板。
- 画布：双击文字编辑，单击图片/视频打开媒体属性；重复项支持新增、复制、隐藏、排序。
- 右侧属性分为：内容、媒体、文字样式、受控位置、绑定诊断。
- 预览采用草稿叠加层；文字和图片优先更新，视频不得成为更新前置条件。
- 位置仅开放模板白名单属性，如偏移、对齐、裁切焦点、层级；越界拒绝保存并说明原因。
- 取消恢复进入编辑前的值；撤销/重做仅操作当前会话变更栈；网络失败保留本地草稿并提供重试。

## 7. 工作流与权限

```text
编辑草稿 → 提交审核 → 审核通过 → 发布
                    ↘ 退回 → 编辑草稿
已发布版本 → 回退到指定历史版本
```

| 角色 | 权限 |
| --- | --- |
| 编辑者 | 修改允许字段、上传媒体、保存草稿、提交审核 |
| 审核者 | 查看差异、通过或退回，不直接修改 |
| 发布者 | 发布已通过版本、回退历史版本 |
| 只读用户 | 查看工作台和公开页面，不写入 |

公开 BFF/API 只能返回已发布记录；草稿和待审核内容仅通过受保护的预览会话访问。
