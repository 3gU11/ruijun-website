## 1. 本次重整结论

本项目不是重新制作官网，也不是开放式网页搭建器。目标是让现有 Nuxt 官网在不改变原 PSD 布局、动画和路由的前提下，能够通过 Directus 工作台对已登记内容进行可视化编辑。

必须区分三种状态：

1. **代码已绑定**：DOM 已声明真实集合、真实记录 id 和精确字段路径。
2. **自动化已验证**：单元/契约测试和构建通过。
3. **业务闭环已验证**：真实 PC 浏览器修改、即时预览、保存、Directus 读取、刷新、撤销/重做和恢复均有证据。

只有第 3 种状态才能计入 P0 完成。测试通过本身不是业务闭环证据。

## 2. 用户目标与工作区

运营人员在一个 PC 工作区内完成：

- 从顶部或左侧进入“网站主页、产品展示、先进制造、视频新闻、关于瑞钧、服务支持”；
- 在中央真实 Nuxt iframe 画布中选中或双击可编辑元素；
- 在顶部工具栏或右侧属性面板修改文字、媒体、排序和受控视觉属性；
- 修改后立即看到画布变化，不等待视频播放结束、不被预览层遮挡；
- 保存草稿、撤销、重做、取消恢复，并能看到失败原因和未保存状态。

工作区布局固定为：顶部操作栏、左侧栏目与页面区块导航、中央真实 PC 画布、右侧属性面板。左侧导航必须直接对应真实页面区块，不得出现重复的“网站主页/网站主页”分类。画布专注模式必须有明确退出入口，且不能永久覆盖属性面板。

## 3. 架构与绑定契约

```text
页面模板层：六个官网栏目
        ↓
Block 层：Banner / TextMedia / ProductList / NewsList / Gallery
          Timeline / ProcessCanvas / Offices / RichText / Video
        ↓
Visual Binding：sectionKey + collection + itemId + fieldPath
                + elementType + mediaRole + placementKey
        ↓
Directus：页面、文章、产品、里程碑、证书、媒体、网点等真实集合
```

每个可编辑元素至少应输出：

```json
{
  "sectionKey": "manufacturing-core-equipment",
  "collection": "manufacturing_evidence",
  "itemId": 3,
  "fieldPath": "media.2",
  "elementType": "image",
  "mediaRole": "image",
  "placementKey": "equipment-3"
}
```

契约规则：

- `collection`、真实 `itemId`、`fieldPath` 任一缺失时只读，不显示保存控件；
- `itemId` 必须来自 Directus 响应，禁止使用 URL、数组下标或字段名推断记录；
- 数组媒体必须保留原始索引，不能因前台过滤、分页或排序改写保存路径；
- 跨集合元素分别保存，部分失败时不得覆盖其他集合的成功结果；
- 保存成功建立新的本地基线；取消恢复最近一次成功基线，不依赖重新请求；
- 视觉属性只允许白名单：位置受控偏移、字体/字号/字重/颜色/行高、媒体适配/焦点/遮罩/海报；
- 位置默认限制为容器比例 `-30..30`，不开放任意 CSS、脚本、外链和无限像素拖拽。

## 6. 继续执行顺序

### P0-1：绑定覆盖

按 `qualifications → manufacturing_evidence → 六页剩余集合` 执行。每个切片先写失败测试，再做最小绑定，确认集合、真实 id 和字段路径。

### P0-2：编辑状态机

覆盖未失焦输入即时同步、保存中/成功/部分失败/网络失败、撤销、重做、取消恢复、切页和未保存离开。保存失败必须保留草稿与操作历史；新编辑必须清除重做分支。

### P0-3：媒体闭环

收到已审核媒体后，验证上传、类型/用途/发布/版权校验、图片与视频即时预览、保存、刷新、撤销和恢复。不得使用演示媒体替代业务样本。

### P0-4：六页 PC 回归

建立“可见元素 → 绑定 → 操作 → 测试 → 浏览器证据 → Directus 证据”表。检查 `1440x900`、`1920x1080`、`3840x2160`；`390x844` 只读检查。任何 Nuxt 原布局、动画、路由、锚点变化都视为回归缺陷。

```text

→ 真实 PC 浏览器修改

→ 撤销/重做/恢复并恢复测试值

```

## 8. 验收标准（Definition of Done）

P0 只有在以下条件全部满足时才能关闭：

1. 六页承诺元素全部真实绑定，或明确标记只读/延期/待建模；
2. 文字、媒体、视觉属性和排序均支持即时预览、保存、撤销、重做、失败恢复和刷新保持；
3. 跨集合操作只写目标 Directus 记录；
4. 真实审核媒体通过类型、用途、发布和版权校验；
5. CMS/Nuxt 测试、扩展构建、Nuxt 构建通过；
6. `8055/4175/3307/9000/9001` 健康检查通过；
7. 测试数据恢复，PC 多分辨率无布局回退，手机端只读不被破坏。

## 9. 风险与明确决策

- “素材不限制数量”只适用于 CMS 存储；前台必须分页、轮播、折叠或懒加载，并承担缩略图、存储和备份成本；
- 任意 PPT 式自由拖拽会破坏 PSD、响应式和维护成本。本期采用受控偏移；若必须自由画布，另立项目并重新建模；
- 证书、地址、电话、负责人和宣传数字可编辑，不等于可以绕过审核直接发布；
- 未发布或未授权内容不能作为公开页面实时闭环证据；
- 若业务暂时不能提供审核媒体，媒体 P0 保持阻断，不用代码或演示数据绕过。
