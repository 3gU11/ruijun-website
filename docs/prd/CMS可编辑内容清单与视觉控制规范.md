# CMS 可编辑内容清单与视觉控制规范

- 版本：v1.3
- 日期：2026-08-22
- 状态：核心能力已实施，内容迁移与业务审核进行中（P0-A 至 P0-D 已完成；媒体规格和发布前校验已具备基础规则；真实素材、宣传数字、联系方式和生产级媒体基础设施仍需业务确认）
- 适用范围：瑞钧官网首页、产品展示、先进制造、视频新闻、关于瑞钧、服务支持，以及全站页头页尾。

## 1. 结论与边界

本清单将官网中可见的文字、图片、视频、图标和列表内容纳入 CMS，并要求每一个可见内容块都可以选择受控的版式、位置和文字样式。

“位置可调”不等于允许录入任意 CSS 或无限制的像素坐标。任意定位会使桌面与手机排版失控，也会破坏现有动画和可访问性。统一采用受控视觉配置：模板、对齐、宽度、间距、桌面/手机偏移、层级、图片裁切焦点和显示顺序。只有在此范围内的调整才允许发布。

当前 CMS 已有草稿、预览、审核、发布和受控媒体流程。统一视觉字段、中文工作台表单、六个独立页面、产品参数/分页、制造画布移动端流程、新闻正文/视频分享、全站页头页尾和“编辑当前条目后跳转到对应位置”的实时预览均已接入并通过自动化或浏览器验收。这里的“已接入”只表示编辑能力和预览链路可用，不表示真实业务内容已经发布；当前公开页面接口返回 `data: null` 时，应按草稿未发布处理，不能据此声称 CMS 内容已被官网读取。

状态释义：`已接入` 指已可在 CMS 草稿中编辑并被页面预览消费；`视觉已接入` 指页面已读取本规范的受控视觉字段；`内容待补齐` 指默认官网内容或真实素材仍需在工作台补齐并审核；`业务待审核` 指能力已完成但宣传数字、版权、联系方式等不能自动代替业务确认；`部分接入` 指字段或前台模块仍未完全对齐；`待实施` 指当前没有可用于前台的完整编辑能力。

## 1.1 CMS 保存结构（P0-A 的单一契约）

所有 `pages.sections` 段落、卡片和媒体项复用下列字段。字段必须由工作台表单生成和校验，公开接口只输出白名单字段；不得存入 `style`、`css`、脚本、任意外链 URL 或不受控定位规则。

```json
{
  "layout": {
    "template": "overlay-left",
    "align_x": "left",
    "align_y": "center",
    "width": "wide",
    "gap": "medium",
    "order": 0,
    "z_index": 1,
    "desktop": { "offset_x": 0, "offset_y": 0 },
    "mobile": { "offset_x": 0, "offset_y": 0 }
  },
  "text_style": {
    "preset": "section-title",
    "weight": 500,
    "size_desktop": 48,
    "size_mobile": 32,
    "line_height": 1.2,
    "color": "#FFFFFF",
    "max_width": "wide"
  },
  "responsive": {
    "desktop_visible": true,
    "tablet_visible": true,
    "mobile_visible": true,
    "mobile_template": "stack"
  },
  "media_presentation": {
    "fit": "cover",
    "focal_x": 50,
    "focal_y": 50,
    "overlay": "dark-30",
    "poster_asset_id": "审核发布的素材 ID"
  }
}
```

可选值与范围：`template` 仅允许项目定义的首屏、双栏、卡片、画廊、时间轴和工艺节点模板；`align_x` 为 `left/center/right`，`align_y` 为 `top/center/bottom`；`width` 为 `narrow/normal/wide/full`；`gap` 为 `none/small/medium/large`；偏移为容器尺寸 `-30%` 至 `30%`，`z_index` 为 `0-9`，焦点为 `0-100`。段落的 `order` 控制阅读顺序；复杂画布仅允许选择已定义节点锚点，不能开放自由拖拽。

## 2. 全站统一编辑能力（P0）

每个页面段落、卡片、按钮、时间轴节点和媒体项都需要以下字段。

| 字段组 | 可编辑字段 | 约束与默认值 |
| --- | --- | --- |
| 内容 | 标题、强调文字、正文、说明、按钮文案、链接、替代文本 | 标题 80 字以内，按钮 24 字以内；链接仅允许站内路由或审核过的 `https` 地址 |
| 排版 | 样式预设、字重、字号、行高、字色、背景色/遮罩、对齐 | 采用预设后再微调；发布前自动检查颜色对比度与文字溢出 |
| 位置 | 版式模板、水平/垂直对齐、宽度、间距、`x/y` 偏移、层级、显示顺序 | 桌面与手机分别保存；偏移范围为容器尺寸的 `-30%` 至 `30%`；层级为 0 至 9 |
| 图片 | 素材、替代文本、显示比例、适配方式、裁切焦点、遮罩、圆角、显示顺序 | `cover/contain` 二选一；焦点 `x/y` 为 `0-100%`；不能直接填写外部不可信地址 |
| 视频 | 视频、首帧海报、播放模式、循环、静音、移动端替代素材、字幕 | 首页首屏默认静音自动播放；预览必须立即展示海报，不能等待视频结束或加载完成 |
| 响应式 | 桌面、平板、手机的显示开关和独立位置/字号 | 手机不能沿用桌面绝对坐标；无手机配置时使用安全的自动堆叠版式 |
| 审核 | 修改说明、来源、版权状态、发布前预览、版本回退 | 媒体必须经过登记、审核、发布后才能被页面引用 |

## 3.1 编辑字段核对表

下表用于将截图中看到的元素落实为 CMS 表单字段。每一行的“位置”均采用第 1.1 节受控配置；图片、视频和图标均从审核发布的媒体资产选择器选择，不能直接填写文件路径或外链。

## 4. 媒体文件需求规格

### 4.1 当前上传限制（已实施）

| 文件类型 | 当前单文件上限 |
| --- | ---: |
| JPG、PNG、WebP、AVIF | 25 MB |
| MP4、WebM | 500 MB |
| PDF | 50 MB |

现有上限限制文件类型和体积；工作台与服务端还会针对用途校验尺寸、比例、视频时长、海报和字幕。下列“建议规格”同时作为上传表单提示和发布前校验规则；建议值不等于对所有历史素材的强制重编码要求。

### 4.2 图片建议规格（工作台已提示，发布前已校验关键字段）

| 使用场景 | 推荐比例与分辨率 | 格式与体积建议 | 必填辅助信息 |
| --- | --- | --- | --- |
| 全屏/首屏背景 | 桌面 16:9，至少 2560 x 1440；手机 3:4 或 9:16，至少 1440 x 1920 | WebP/AVIF 优先，JPG 可用；建议不超过 3 MB | 替代文本、桌面/手机裁切焦点、版权说明 |
| 宽幅横移背景/时间轴背景 | 8:3 至 3:1，至少宽 2560 px | WebP/AVIF/JPG，建议不超过 3 MB | 替代文本、裁切焦点、遮罩建议 |
| 产品/设备主图 | 1:1 或 4:3，至少 1600 x 1200 | 透明背景使用 PNG/WebP；建议不超过 2 MB | 产品名称、替代文本、`contain/cover` 适配方式 |
| 卡片/新闻封面 | 16:9，至少 1600 x 900 | WebP/JPG，建议不超过 1.5 MB | 标题、替代文本、裁切焦点 |
| 证书/参数/尺寸图 | 原始比例，长边至少 2000 px | PNG/JPG/PDF；建议不超过 10 MB | 名称、编号/版本、来源、有效期（适用时） |
| 厂区/客户/图库照片 | 4:3 或 3:2，至少 1600 x 1200 | WebP/JPG，建议不超过 2 MB | 标题、替代文本、拍摄/授权说明 |
| 图标/标志 | SVG 优先；位图至少 512 x 512 | SVG 或透明 PNG/WebP，建议不超过 300 KB | 名称、用途、浅/深色适配、版权说明 |
| 地图/区域图 | 16:9 或与设计稿一致，至少 1920 x 1080 | WebP/JPG，建议不超过 2 MB | 区域名称、替代文本、导航链接（可选） |

### 4.3 视频建议规格（工作台已提示，发布前已校验关键字段）

| 使用场景 | 编码与分辨率 | 时长/体积建议 | 必填字段 |
| --- | --- | --- | --- |
| 首页/页面首屏循环视频 | MP4（H.264 + AAC），1920 x 1080；可补充 WebM | 15-60 秒，无声或静音循环；建议不超过 80 MB | 首帧海报、移动端替代海报或短视频、替代文本、版权说明 |
| 新闻/视频分享 | MP4（H.264 + AAC），1920 x 1080 | 单条建议不超过 30 分钟、300 MB | 标题、日期、首帧海报、摘要、字幕文件或文字稿 |
| 工艺/设备演示 | MP4（H.264 + AAC），1920 x 1080 | 建议不超过 10 分钟、200 MB | 标题、机型、版本、说明、字幕、版权说明 |

视频封面默认取第一帧，但 CMS 必须允许更换海报，避免首帧是黑屏或转场。所有实时预览都先渲染海报和文本，再异步加载视频；视频加载失败时保留海报和提示，不阻塞页面或预览跳转。

## 5. CMS 操作方式

1. 在“内容编辑工作台”选择页面或内容类型，编辑文字、排序和视觉配置。
2. 在“更多工具 - 媒体资产”上传素材，填写用途、替代文本、版权/授权信息和建议规格提示。
3. 媒体审核发布后，回到页面段落选择素材，并设置裁切焦点、显示比例和桌面/手机位置。
4. 使用“预览当前草稿”检查未保存文字；保存后使用“在官网中预览草稿”检查完整页面、桌面和手机布局。
5. 通过文字溢出、颜色对比度、媒体规格、链接安全性和移动端布局检查后，提交审核与发布。

## 7. 风险与待确认事项

- 证书、专利、网点地址、负责人、电话和宣传数字均属于需要业务确认的信息；CMS 能编辑不代表可以直接对外发布。
- 图片和视频的“不限量存放”应理解为素材库容量可扩展，而不是单个页面无限渲染。页面必须设置首屏展示数量、分页或懒加载，避免性能恶化。
- 每个页面需要业务方确认哪些区块允许改版式，哪些区块只允许换内容。复杂 PSD 画布不适合开放任意拖拽，应先拆成可管理的节点和模板。
- 当前媒体选择器仅显示审核已发布素材；若素材库为空，选择器会禁用。这是版权与审核约束，不应绕过。
- 生产环境仍需要对象存储、图片处理/CDN、视频转码、备份和 HTTPS；本地 CMS 流程不能替代这些生产能力。
