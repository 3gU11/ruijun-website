## 1. 产品定义

Visual Editing 是“真实 Nuxt 页面 + 受控可视化编辑”，不是通用建站器：运营人员在一个 PC 工作台中选择页面元素，修改已登记的 Directus 内容，立即在真实 Nuxt 画布中看到结果，再保存为草稿并进入审核发布流程。

### 目标

- 六个官网页面按真实页面区块管理，不能出现重复的两层页面分类。
- 文字、图片、视频、列表内容及白名单视觉属性可在画布中编辑。
- 预览不遮挡编辑面板，不等待视频播放结束，选中后自动定位到真实元素。
- 不改变 Nuxt 原有 PSD 布局、动画、路由、锚点、断点和响应式结构。
- 每次写回都能证明真实 `collection + itemId + fieldPath`，并支持草稿、审核、发布、回退。

### 明确不做

- 任意 HTML/CSS/JavaScript、外链注入、模板代码编辑。
- 不受约束的像素级自由拖拽、改版或重排页面结构。
- 本阶段手机端原位编辑、模板市场和自由区块拼装。
- 用 PSD、static fallback、测试 PDF、生成素材或演示资讯冒充正式媒体闭环。

## 3. 编辑与数据契约

每个可编辑 DOM 必须携带稳定绑定：

```json
{
  "sectionKey": "service-offices",
  "collection": "service_locations",
  "itemId": 1,
  "fieldPath": "service_scope",
  "elementType": "text",
  "mediaRole": null,
  "placementKey": null
}
```

规则：

1. 缺少 `collection`、真实 `itemId` 或合法 `fieldPath` 时只读，不显示可保存控件。
2. 禁止用数组下标、显示文本或猜测字段定位记录。
3. 跨集合绑定必须显式声明并与当前预览会话匹配。
4. 媒体必须经过集合白名单、发布状态、版权、类型、用途和 `placementKey` 校验。
5. 多集合保存要分别记录结果；任一失败都保留本地草稿和历史，不清空未保存内容。

允许的视觉字段：

```text
layout.enabled / align / offset_x / offset_y / max_width
text_style.enabled / preset / font_family / size_desktop / weight / line_height / color
media_presentation.fit / focal_x / focal_y / overlay / poster_asset_id
```

所有偏移、字号、字体、颜色和尺寸都由模板白名单和范围校验控制。

## 5. 继续执行工作包

### P0-0：业务输入确认（阻断前置）

业务方必须提供并确认：正式图片和视频、版权/授权、用途与位置、格式/大小/像素/时长要求、新闻与视频日期时区、演示资讯处理清单、编辑/审核/发布角色及是否允许兼任。

未确认前只能完善代码、测试和诊断，不得把媒体闭环标为完成。

### P0-1：正式媒体闭环

导入 Directus 文件和 `media_assets` 草稿，核验文件元数据、MinIO 对象、版权、发布状态、用途和 `placementKey`；审核发布后，在六页各选至少一个真实图片、背景或视频位置完成替换。

验收必须包含：合规素材可选；未发布、未授权、类型/用途/位置不匹配素材不可选；图片、视频、背景即时变化；视频先显示海报/文字，不等待播放；保存、刷新、回读和失败恢复一致；无孤儿媒体引用。

### P0-2：逐集合真实绑定矩阵

按 `articles`、`product_series`、`product_models`、`milestones`、`qualifications`、`manufacturing_evidence` 顺序，每个集合至少选一个真实元素完成：画布选中、临时修改、即时预览、保存、Directus 回读、刷新保持、原值恢复，并记录准确的 `collection/itemId/fieldPath`。

未完成绑定的元素必须显示为只读、待建模或延期，不能显示一个看似可用但不会写回的编辑器。

### P0-3：新闻与视频列表行为

用真实内容验证标题、日期、封面、图文正文和视频媒体的新增/编辑/隐藏/排序；前台每页最多 6 条、日期倒序、分页；新闻点击进入图文详情并安全渲染；视频封面取首帧且首帧不可用时明确显示备用海报和错误状态。

### P0-4：审核、发布与回退

用真实岗位验证草稿 → 提交审核 → 通过/退回 → 发布 → 下线/归档 → 版本回退。公开接口只能返回已发布内容，预览使用受保护会话；任何权限越界、草稿泄露、版本回退不一致都阻止发布。

### P0-5：PC 收口与手机只读回归

在 1440x900、1920x1080、3840x2160 检查工作台和官网无覆盖、溢出、错位；在 390x844 检查公开页面无横向溢出和明显重叠，手机端不开放编辑。额外覆盖视频播放、阻止、加载失败、断网重试和切页未保存提示。

## 6. TDD 与证据要求

每个工作包固定执行：

```text
失败测试 -> 最小实现 -> 定向测试 -> CMS/Nuxt 全量测试
-> 扩展/生产构建 -> 真实 PC 浏览器 -> Directus 受保护回读
-> 刷新一致 -> 恢复测试数据 -> 更新验收记录
```

每个样本至少记录：页面、区块、可见元素、绑定四元组、原值/临时值/回读值/恢复值、预览是否等待视频、保存结果、Directus 返回值、刷新结果和验收时间。不得记录密码、token 或把 HTTP 200、缓存、`data:null` 当作内容证据。

## 7. 停止与发布门槛

出现以下任一情况，停止当前切片并回到评审：

- 修改破坏 Nuxt 原 PSD 几何、动画、路由、锚点、断点或响应式。
- 公开接口读取到草稿或未授权媒体。
- 画布与 Directus 回读不一致，或失败保存留下半成品引用。
- 正式素材、版权、规格或业务审批规则缺失。

Visual Editing P0 只有在以下条件全部满足后才能宣布完成：六页承诺元素均已真实绑定或明确只读/延期；文字、媒体、位置、样式、列表和失败恢复闭环通过；审核发布回退有效；CMS/Nuxt 全量测试和生产构建通过；PC 六页回归通过；手机公开页面只读回归通过；所有临时测试值已恢复。
