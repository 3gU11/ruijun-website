## 1. 先确认前提

### 1.1 已确认的产品方向

本项目要做的是“模板约束的可视化编辑工作台”：编辑人员进入六个 Header 页面，在真实 Nuxt PC 画布中选择元素，在右侧修改内容，立即看到草稿效果，再保存、回读和发布。

### 1.2 不能同时成立的要求

“像 PowerPoint 一样任意拖动、缩放和修改 CSS”与“原 Nuxt 布局、PSD 几何、动画、路由和响应式完全不变”存在直接冲突。本版本只实现受控编辑：画布选择、文字双击编辑、媒体替换、有限位置和样式；不实现任意 HTML/CSS 搭建。

如果以后需要自由搭建专题页，应另立项目，不能直接改造这六个受保护官网模板。

### 1.4 不能作为完成证据

HTTP `200`、`data: null`、缓存、截图、静态 fallback、PSD 图片、iframe 可见、红框可选中、工作台出现字段，都不能单独证明 CMS 已真实接入。完成证据必须包含：正确集合、记录 ID、字段路径的认证 Directus 回读，以及刷新和原值恢复。

## 2. 目标与非目标

### 2.1 本阶段目标

1. 按六个 Header 页面管理，不再出现重复的两层页面分类。
2. 每个承诺可编辑的元素都能追溯到稳定的数据目标。
3. 先完成文字和列表的真实闭环，再开放正式媒体和受控版式。
4. 编辑区、预览区、属性区同时可见，预览不遮挡输入，也不被视频结束、动画或页面跳转阻塞。
5. 不改变既有 Nuxt 页面布局、动画、路由和 PC 响应式。

### 2.2 本阶段不做

- 任意 DOM 结构、任意坐标、任意 CSS、任意断点的自由编辑。
- 未导入 Directus 文件和 MinIO 对象的 PSD/static 图片或视频替换。
- 保存草稿自动发布公开官网。
- PC 逐页验收前的移动端可视化编辑器。

## 3. 页面与区块信息架构

工作台固定采用以下层级：

```text
六个 Header 页面
  -> 当前页面真实业务区块
    -> 真实 Nuxt 画布元素
      -> Directus 集合/记录/字段
```

六个页面及其一级区块如下：

| 页面 | 一级区块 |
| --- | --- |
| 网站主页 | 首页视频、三大理由、产品系列、横移图文、时间轴、选型咨询、页尾 |
| 产品展示 | 首屏、分类、产品系列、型号参数、尺寸图、资料 |
| 先进制造 | 首屏、工艺画布、制造区域、生产核心设备 |
| 视频新闻 | 首屏、动态新闻、视频分享、新闻详情 |
| 关于瑞钧 | 品牌故事、时间轴、厂区、认证/荣誉/专利、合作品牌、国内客户、国外客户 |
| 服务支持 | 首屏、瑞钧支持、适用型号、服务入口、直属办事处 |

左侧只显示当前页面的一级区块和相关业务记录，不放置重复页面分类，也不把整页表单挤进导航栏。

## 4. 工作台交互规格

### 4.1 三栏布局

- 顶部工具栏：页面/区块路径、选择模式、文字模式、媒体模式、撤销、重做、缩放、保存草稿、预览状态。
- 左侧区块栏：当前页面区块、搜索、折叠、列表分页。
- 中央画布：真实 Nuxt PC iframe。编辑模式拦截原页面跳转、视频播放和展开行为；浏览模式恢复官网行为。
- 右侧属性栏：内容、媒体、受控样式、受控位置、绑定诊断、错误和恢复。

三栏必须实际占位。预览不得以浮层覆盖右侧输入区，也不得通过等待视频或动画结束才能选中元素。

### 4.2 元素绑定契约

每个可写元素必须有完整绑定：

```json
{
  "pageKey": "about",
  "sectionKey": "overview",
  "collection": "pages",
  "itemId": "2",
  "fieldPath": "sections[overview].body",
  "elementType": "text",
  "mediaRole": null,
  "placementKey": null
}
```

缺少集合、记录 ID 或字段路径时必须显示“只读/待建模/待媒体”和原因。禁止按显示文字、数组下标、DOM 坐标、文件名或旧侧栏快照猜测写入目标。跨页面、跨区块、跨集合切换后必须清空旧选中态和保存目标。

### 4.3 支持能力

| 能力 | 本期范围 | 限制 |
| --- | --- | --- |
| 文字 | 标题、正文、按钮、年份、参数、链接说明 | 稳定字段、富文本安全过滤 |
| 文字样式 | 字体、字号、字重、行高、颜色、对齐 | 区块白名单、范围校验、可恢复默认值 |
| 媒体 | 图片、视频、海报、图标、替代文本、焦点 | Directus 文件 + `media_assets` + MinIO 实物 |
| 位置 | 对齐、有限偏移、最大宽度、层级、显隐 | 受区块边界限制，不改模板结构 |
| 列表 | 新增、排序、隐藏、分页/轮播 | 每项独立真实 ID，删除可恢复 |

## 5. 六页内容要求

“纳入范围”不等于“已完成”。逐字段状态以绑定台账和验收记录为准。

| 页面 | 必须可管理的内容 |
| --- | --- |
| 网站主页 | 首屏视频/海报、三大理由文字/缩略图/图标、产品系列卡、横移背景和文字、时间轴背景/年份/文段、选型咨询、页尾文字/链接/图标 |
| 产品展示 | 页面文字、下拉分类文字和图片、型号、参数及单位、尺寸图、资料、分页 |
| 先进制造 | 首屏图片、工艺节点图片和文字、连接图和标签、制造区域文字和图片、生产核心设备标题、设备媒体库和排序 |
| 视频新闻 | 首屏视频、动态新闻标题/日期/封面/图文详情、视频分享标题/视频/首帧封面、分页 |
| 关于瑞钧 | 首屏背景及红框文字、品牌故事、共享时间轴、厂区/认证/荣誉/专利图库、合作品牌、国内客户、国外客户标题和图片 |

“不限量存放”只表示 CMS 可继续新增记录。前台必须定义分页、轮播、折叠或懒加载；视频新闻和动态新闻每页最多 6 条，按业务日期降序，同日必须有明确的次级排序字段。

## 6. 媒体治理

图片或视频开放替换前，必须同时存在：Directus 文件记录、`media_assets` 业务记录、MinIO 对象、用途、版权/来源、替代文本、发布状态、PC 裁切焦点和适配方式。

| 用途 | 最低建议规格 |
| --- | --- |
| 首屏图片/视频 | 图片 `2560x1440`；MP4 H.264 `1920x1080`、15-60 秒 |
| 产品/设备图 | `1:1` 或 `4:3`，至少 `1600x1200` |
| 新闻封面 | `16:9`，至少 `1600x900` |
| 证书/尺寸图 | 原比例，长边至少 `2000px` |
| 图标/标志 | SVG 优先；位图至少 `512x512` |

视频首帧抽取失败时必须提示并允许人工指定海报。`media_assets=0` 时，未托管媒体一律只读，不得伪装成已完成替换。

## 7. 状态、权限与发布

目标状态：`draft -> in_review -> published -> archived`。

| 角色 | 允许 | 不允许 |
| --- | --- | --- |
| 编辑者 | 修改、保存草稿、上传待审核素材、提交审核 | 直接发布、不可恢复删除 |
| 审核者 | 预览、通过、退回 | 绕过流程修改模板结构 |
| 发布者 | 发布、下线、版本恢复 | 绕过审核发布 |

离开有未保存修改的页面必须提示。保存失败时保留本地草稿，显示服务端错误，并支持重试。

## 9. 单项验收协议

所有字段、媒体和列表能力都必须执行：

```text
失败测试 -> 最小修复 -> 定向测试 -> 构建
-> 真实 PC 画布选中 -> iframe 即时草稿预览
-> 保存草稿 -> 认证 Directus 回读 -> 工作台/页面刷新一致
-> 同一路径恢复原值 -> 最终认证回读 -> 更新绑定台账
```

标记“已闭环”必须同时满足：

1. 画布命中正确集合、记录 ID、字段路径。
2. 临时值在同一 iframe 立即可见，不依赖视频结束或重新进入页面。
3. 保存后认证回读正确，刷新后仍一致。
4. 测试值已恢复，最终回读无残留。
5. 原 Nuxt 布局、动画、路由和响应式没有改变。

## 10. 暂停条件与待业务确认

以下情况不能由开发自行猜测：

1. 需要改变 Nuxt/PSD 几何、动画、路由或响应式。
2. 没有正式素材、版权或用途信息却要求媒体可替换。
3. 同时要求自由拖拽和原布局完全不变。
4. 要删除演示资讯、证书、媒体或历史内容但未提供删除清单。
5. 未定义新闻日期时区、同日排序、审核人和发布责任人。
6. 要公开草稿但未完成发布状态和权限验收。
