# 瑞钧官网 CMS 可视化编辑后续执行 PRD

- 版本：v2.0（重整稿）
- 日期：2026-08-26
- 状态：待业务确认后执行
- 适用范围：PC 官网与 Directus 内容编辑工作台
- 关联资料：[CMS 可视化编辑绑定台账](CMS可视化编辑绑定台账.md)、[现行执行 PRD](CMS可视化编辑继续执行PRD.md)

## 1. 本次要解决的真实问题

当前工作台已有“真实官网画布 + 点击元素 + 属性面板 + 草稿保存”的基础能力，但内容入口、元素绑定、媒体治理和发布流程尚未完成一致性验收。编辑人员现在会遇到三类问题：

1. 官网画布看得到的内容，左侧不一定找得到对应区块。
2. 区块显示为可编辑，不等于存在可保存、可回读的 Directus 字段。
3. PSD/static fallback 图能在官网显示，但没有纳入 CMS 媒体记录，不能安全承诺“可替换”。

因此，本期目标不是继续扩张一个自由拖拽的网页制作器，而是完成六个 PC 页面中已承诺内容的可追溯、可编辑、可预览、可保存和可恢复闭环。

## 2. 结论先行：可交付范围与不做事项

### 2.1 本期交付

编辑者在工作台中按 Header 的六个页面进入一个页面级画布；左侧只显示该页面的业务区块，点击区块后定位真实 Nuxt 页面区域，点击画布元素后在右侧属性面板修改允许的内容。

受支持的修改范围：

| 对象 | 支持内容 | 前提 |
| --- | --- | --- |
| 文本 | 标题、正文、按钮文案、年份、参数、链接说明 | 有真实集合、记录 ID 和字段路径 |
| 媒体 | 图片、视频、海报、图标、替代文本、焦点、适配方式 | 已导入 Directus 文件和 `media_assets`，并有用途绑定 |
| 受控样式 | 字号、字重、行高、颜色、对齐 | 页面区块白名单允许，且不改变模板结构 |
| 受控位置 | 对齐、有限偏移、宽度、层级、显示开关 | 仅限白名单字段与模板允许范围 |
| 列表 | 新增、排序、隐藏、分页 | 每项有独立真实 ID，删除可恢复 |

### 2.2 本期明确不做

以下诉求不能与“保留现有 Nuxt / PSD 布局、动画和响应式”同时无成本成立，故不列入本期验收：

- 任意元素自由拖动、任意缩放、任意改 CSS 的 PPT 式网页搭建。
- 静态 PSD、硬编码图片或视频在未导入 CMS 前直接“替换”。
- 以 HTTP 200、缓存命中或 `data: null` 当作 CMS 已真实读取的证明。
- 在 PC 功能尚未逐页闭环前，扩展手机端可视化编辑。

若未来需要全自由画布，应独立立项：需要桌面/移动断点模型、碰撞规则、版本迁移、回滚、性能预算和无障碍策略，不能在当前模板约束编辑器上直接追加。

## 4. 产品结构

```text
Header 页面（六项）
  -> 当前页面业务区块（不重复 Header 分类）
    -> 真实 Nuxt iframe 画布中的可编辑元素
      -> Directus 的稳定写入目标
```

每个可编辑元素必须具备完整绑定，不允许按文字、视觉坐标、数组下标或文件名猜测保存位置：

```json
{
  "pageKey": "homepage",
  "sectionKey": "product-task",
  "collection": "pages",
  "itemId": "1",
  "fieldPath": "sections[product-task].title",
  "elementType": "text",
  "mediaRole": null,
  "placementKey": null
}
```

任一字段缺失时，界面必须显示“只读 / 待建模 / 待媒体”与原因，不得将其伪装成可编辑。

## 6. 编辑工作流与交互要求

1. 从工作台 Header 页面选择一个页面，默认进入该页画布总览。
2. 左侧展示该页业务区块，不能再次显示同一套 Header 分类，也不能把整页表单塞进侧栏。
3. 点击区块后，画布滚动并高亮对应区块；例如首页“选型咨询”必须定位 `product-task`。
4. 点击画布元素后，右侧显示字段名、当前值、允许操作、数据来源和状态。
5. 修改应立即在 iframe 内预览；编辑模式须阻止链接跳转、视频播放和折叠事件干扰选中。
6. 保存仅保存已经变动的真实写入目标；成功后需能刷新验证。离开未保存页面必须提示。
7. 预览与编辑输入区域并排，不覆盖右侧属性面板；视频加载、自动播放失败和视频结束不得阻塞选中或保存。

## 7. 数据、媒体、状态与权限

### 7.1 内容状态

目标状态机：`draft -> in_review -> published -> archived`。

本期先完成草稿编辑和授权预览闭环；审核、发布、下线、回退、审计与角色隔离列为后续 P1。公开 Nuxt 只读 `published`，授权预览会话可读取对应草稿。

### 7.2 媒体准入

媒体替换前必须具备：Directus 文件记录、`media_assets` 业务记录、MinIO 对象存在、用途、替代文本、版权/来源和发布状态。不能把磁盘静态资源或 PSD 导出文件当作 CMS 文件。

最低建议规格：

| 用途 | 最低规格 | 必填元数据 |
| --- | --- | --- |
| 首屏图/视频 | 图 `2560x1440`；MP4 H.264 `1920x1080`，15-60 秒 | 海报、替代文本、焦点、版权 |
| 产品/设备图 | `1:1` 或 `4:3`，至少 `1600x1200` | 名称、替代文本、适配方式 |
| 新闻封面 | `16:9`，至少 `1600x900` | 标题、业务日期、替代文本、焦点 |
| 证书/尺寸图 | 保持原比例，长边至少 `2000px` | 名称、来源、编号/版本、有效期（如适用） |
| 图标/标志 | SVG 优先；位图至少 `512x512` | 名称、用途、深浅色适配、版权 |

## 8. 实施阶段与验收

### P0-A：修复当前页面区块导航（已完成，2026-08-26）

范围：把首页已有的 `product-task` 加入“网站主页内容”的工作台区块清单，名称建议为“选型咨询”。

验收：点击入口后，工作台打开首页页面记录，设置 `activePageSectionKey=product-task`，iframe 滚动并高亮底部联系区；不改变 Nuxt 画面。

**完成证据**：先新增失败的源码契约测试，确认修复前缺少 `homepage-product-task`。最小修复后，CMS 定向测试 `18/18` 通过，扩展构建成功并重启 Directus。真实浏览器刷新后显示“选型咨询”；点击后按钮为激活状态、首页草稿表单出现 `product-task` 标题、真实 Nuxt iframe 同时显示“让下一台设备匹配你的加工任务”，控制台 `0` 错误。此项只证明入口与定位，不证明该字段已写入保存。

### P0-B：六页逐元素绑定审计

为六页每个承诺元素建立或补全绑定台账，字段包括：页面位置、Nuxt 组件、区块键、集合、记录 ID、字段路径、编辑权限、媒体状态、当前证据、未实现原因。

验收：所有承诺项均被标为“可写入 / 已声明待闭环 / 只读待媒体 / 待建模”之一。禁止用“页面有入口”替代逐元素结论。

### P0-C：每页一个真实写入闭环

按下列顺序为每页选一个低风险、未覆盖字段完成闭环。产品页既有样本可作为证据，但仍要为其他产品字段补样本。

| 页面 | 首选样本 |
| --- | --- |
| 网站主页 | `pages/1.sections[product-task].title` |
| 产品展示 | `product_parameters/94.value` 已完成；下一项选择其他型号参数或受治理尺寸图 |
| 先进制造 | `pages/8.sections[precision-machining].title` |
| 视频新闻 | 未被使用的 `articles/{id}.summary`、`title` 或业务日期 |
| 关于瑞钧 | `pages/2.sections[overview].title` 或共用里程碑字段 |
| 服务支持 | `pages/3.sections[support].title` 或 `service_locations/{id}.address` |

单项验收顺序固定为：画布选中 -> 即时预览 -> 保存草稿 -> 受保护 Directus 回读 -> 整页刷新一致 -> 从同一工作台恢复原值 -> 再次回读。

**首页完成证据，2026-08-26**：`pages/1.sections[product-task].title` 已通过画布点击选中为 `pages · title`。修复 Visual Editing 错写原始列表快照的问题后，临时值 `让下一台设备匹配你的加工任务-TDD` 立即同步到属性面板、页面表单与真实 Nuxt iframe，保存草稿可用；认证 Directus 回读为临时值，完整刷新工作台后仍存在。随后在同一画布路径恢复原文并保存，最终回读确认原值已恢复。

### P0-D：正式媒体治理与一条媒体闭环

业务方提供具有用途和版权信息的正式素材。系统导入后，完成一条图片或视频的替换、预览、保存、受保护回读、刷新与恢复。

`media_assets=0` 未改变前，本阶段不可验收，也不能对外承诺图片/视频已可在 CMS 替换。

### P1-A：可扩展列表能力

实现新闻、视频、核心设备、品牌、客户图库、产品资料与尺寸图的新增、排序、隐藏和展示策略。视频默认取首帧；首帧抽取失败时允许人工上传海报并显示错误状态。

### P1-B：生产治理能力

实现审核、发布、下线、版本回退、失败重试、操作审计和角色隔离。编辑者、审核者、发布者的权限需分开验证。

## 9. 工程约束与质量门槛

每个实现切片必须遵循：

```text
失败测试 -> 最小实现 -> 定向测试 -> 扩展构建
-> 真实 PC 浏览器 -> 认证 Directus 回读 -> 刷新一致
-> 恢复测试值 -> 更新 PRD 与绑定台账
```

通过条件：

1. 不修改现有 Nuxt 页面视觉布局、PSD 几何位置、动画与响应式行为。
2. 工作台在 PC `1440x900`、`1920x1080`、`3840x2160` 下不遮挡编辑输入区域。
3. 所有临时测试值均恢复，且恢复由受保护 Directus 回读证明。
4. 不能把 HTTP `200`、缓存结果、`data: null`、fallback 或静态文件当作真实 CMS 内容证据。
5. 当前阶段只回归移动端公开官网无明显横向溢出、重叠或不可读文字；移动端可视化编辑另立阶段。

## 10. 主要风险与待确认事项

| 风险/问题 | 影响 | 处理方式 |
| --- | --- | --- |
| 现有 Nuxt 数据与 CMS 记录不一致 | 编辑后官网不变或写错字段 | 先完成 P0-B 台账，再允许写入 |
| 静态/PSD 媒体未治理 | “替换”后无法追踪、回退或发布 | P0-D 前只读标记 |
| 页面全部为草稿 | 公开官网无法反映编辑结果 | 明确授权预览与发布流程，不能混淆 |
| 自由拖拽与原布局冲突 | 破坏响应式、动画和视觉一致性 | 保持模板约束，只开放白名单布局字段 |
| “不限量”没有前台策略 | 页面性能和可用性下降 | 每类列表定义分页/懒加载/轮播上限 |

需要业务确认但不阻塞 P0-A/P0-B：正式素材与版权责任、演示资讯删除或替换规则、允许调整的样式/位置范围、新闻日期时区与同日排序、编辑/审核/发布是否分账号、对外联系电话与宣传数值。
