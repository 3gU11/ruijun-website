- 版本：v25.0
- 日期：2026-08-26
- 状态：待评审后继续执行
- 编辑终端：PC 优先；手机端仅做公开页面只读回归
- 关联系统：Nuxt 官网、Directus CMS、MinIO、MySQL `127.0.0.1:3307`

## 1. 背景与问题定义

当前 CMS 已具备受控可视化编辑、草稿、预览和发布的基础，但仍存在三个产品层问题：

1. 工作台必须与官网真实画布一一对应，不能出现“CMS 有字段、官网没有内容”或“官网有内容、工作台找不到”的情况。
2. 编辑预览不能覆盖编辑界面，也不能因为视频加载或播放阻塞文字、图片和布局修改。
3. 六个网站页面需要按页面和真实区块组织管理，不能把同一页面拆成重复的两层分类。

本 PRD 将继续建设 Visual Editing，而不是重做 Nuxt 页面或建设无限自由度的建站器。

## 2. 产品目标与非目标

### 2.1 目标

- 在一个 PC 编辑器窗口中完成“选择页面 → 选择区块/元素 → 修改 → 画布预览 → 保存草稿”。
- 支持文字、图片、视频、列表数据、受控位置和文字样式的可视化编辑。
- 保持 Nuxt 现有布局、PSD 坐标、动画、路由、锚点、断点和响应式结构不变。
- 所有正式内容经过 Directus 草稿、审核、发布后才进入公开页面。
- 用可复现的浏览器证据和 Directus 受保护接口回读证明每个功能，而不是只看 HTTP 200 或测试数量。

### 2.2 非目标与约束

- 不允许 CMS 写入任意 HTML、CSS、JavaScript 或组件代码。
- 不支持任意画布自由拖拽、任意缩放页面结构或破坏模板布局的定位。
- “位置可调”仅指模板白名单中的偏移、对齐、裁切焦点、层级和尺寸范围。
- 正式图片、视频、版权和规格未提供前，不得用生成素材、PSD 或 static fallback 伪装成媒体闭环。
- 删除演示资讯前必须备份并获得明确确认。

## 4. 编辑器体验

### 4.1 固定 PC 布局

- 顶部工具栏：页面切换、编辑模式、选择/文字/媒体、撤销、重做、缩放、保存草稿、预览、状态。
- 左侧页面树：六个页面及其真实区块；只承担导航，不覆盖画布。
- 中间画布：真实 Nuxt iframe；选中元素高亮，自动滚动到元素位置。
- 右侧属性面板：内容、媒体、列表、文字样式、受控位置、绑定诊断。

### 4.2 编辑行为

- 单击图片/视频打开媒体属性；双击文字进入编辑；重复内容可新增、复制、隐藏和排序。
- 文字属性：模板允许的字体、字号、粗细、颜色、行高、对齐和换行策略。
- 位置属性：模板允许的 `x/y` 偏移、宽高、对齐、层级、裁切焦点；所有值做范围校验。
- 预览通过草稿叠加层更新，文字和图片优先同步，不等待视频播放结束。
- 取消恢复编辑前快照，并立即刷新画布；撤销/重做只作用于当前会话。
- 断网或保存失败时保留本地草稿、显示失败原因并允许重试，不能留下半成品媒体引用。

## 5. 数据与绑定契约

每个可编辑元素必须显示并保存稳定绑定：

```json
{
  "collection": "product_series",
  "itemId": "1",
  "sectionKey": "series-card",
  "fieldPath": "title"
}
```

- `itemId` 必须为 Directus 真实主键，禁止使用数组下标或显示文本定位。
- `sectionKey` 跨刷新稳定；`fieldPath` 支持嵌套字段和媒体字段。
- fallback、PSD/static 层和未托管外链只读，并在诊断面板标明原因。
- 媒体记录至少包含文件类型、大小、宽高/时长、首帧状态、对象键、发布状态和失败状态。
- 新闻正文使用受控富文本；公开端必须清理脚本和危险属性。

## 6. 内容工作流与权限

状态机：`编辑草稿 → 提交审核 → 审核通过 → 发布`；审核可退回，发布者可恢复历史版本。

- 内容编辑者：创建和修改草稿，不得发布媒体和页面。
- 审核管理：查看、审核、退回，并按授权恢复版本。
- 系统管理/发布者：发布、下线、归档和回退。
- 是否允许同一账号兼任，必须由业务确认后配置，不能在代码中默认放开。

公开接口只返回已发布内容；草稿预览必须使用受保护会话和草稿叠加层。
