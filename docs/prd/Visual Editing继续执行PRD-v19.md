## 1. 产品结论

目标是让运营人员在真实 Nuxt 官网画布中选择区块或元素，在类似 PowerPoint/HTMLPage Builder 的工作台内修改内容并立即看到草稿效果。这里的“可视化编辑”不是重做官网，也不是任意拖拽建站器：页面模板、PSD 坐标、动画、路由、锚点和响应式结构继续由 Nuxt 代码控制；CMS 管理内容、媒体、重复项和受控视觉参数。

因此，“六个页面所有内容都可编辑”必须拆成两类：

1. 业务内容：文字、图片、视频、新闻、产品、证书、客户、办事处等，必须有 Directus 记录和唯一绑定，可编辑、保存、回读。
2. 模板内容：布局、动画时序、任意 CSS/HTML/脚本、PSD 装饰层不是本期 CMS 字段；页面中若没有真实数据来源，必须明确显示为只读或待建模，不能用 fallback 冒充已接入。

## 2. 成功标准

PC 六页满足以下闭环后，才能宣布 P0 完成：

- 工作台按“一级页面 → 真实区块”组织，不能出现两层相同分类。
- 画布点击可定位到区块，并打开正确的 Directus 集合、记录 id 和字段。
- 修改在预览中显示临时值，不需等待视频结束；预览不会覆盖编辑面板。
- 保存后可从 Directus 精确回读，刷新仍保持；取消、撤销、重做和恢复原值有效。
- 图片/视频有文件元数据、MinIO 对象和前台渲染证据；失败不会产生半条业务记录。
- 重复内容支持新增、编辑、排序、隐藏和分页；新闻/视频分享每页最多 6 条，按日期倒序。
- 草稿、审核、发布、退回和回退在 API 权限层生效，公开接口不泄漏草稿。
- Nuxt 原布局、坐标、动画、路由、锚点和响应式无非内容性变化。

## 3. 不做与硬约束

- 不改 Nuxt 原有页面布局和交互结构。
- 不保存任意 HTML、CSS、JavaScript、本地路径或未经治理的外链。
- 不提供无限像素级拖拽。位置编辑仅限模板白名单：排序、对齐、焦点、间距和有限偏移；服务端校验范围。
- 不复制时间轴主数据。首页和关于瑞钧只保存展示配置，共用同一组里程碑记录。
- 不删除演示数据，除非先备份并由业务确认删除清单。
- 不把 PSD 静态层、代码 fallback 或无 Directus 文件记录标为可编辑。

## 5. 统一编辑模型

每个画布元素必须带有以下绑定契约，`itemId` 只能使用 Directus 稳定记录 id：

```json
{
  "collection": "product_series",
  "itemId": "1",
  "sectionKey": "series-card",
  "fieldPath": "title"
}
```

工作台布局：顶部工具栏（页面、选择、文字、媒体、撤销/重做、缩放、保存、预览），左栏页面和真实区块，中栏 1440x900 Nuxt 画布，右栏内容/媒体/版式/文字样式/状态/绑定诊断。画布选中元素后，最近的嵌套根节点优先，打开对应表单而非外层 `pages` 记录。

文字样式仅允许字体、字号、字重、颜色、行高、对齐和有限偏移；图片允许裁切模式、焦点和白名单尺寸；视频允许文件、首帧、静音、播放策略和时长校验。预览同步目标为 300ms 内开始，断连时保留本地草稿并提示错误。

## 6. 内容、媒体和列表规则

- 新闻字段：标题、业务日期、封面、图文详情、发布状态；点击封面展开详情。
- 视频分享字段：标题、业务日期、视频文件；默认用视频首帧生成封面，可人工替换。
- 新闻和视频分享同一页最多 6 条，按业务日期倒序，超过 6 条进入下一页。
- 产品、设备、证书、客户、合作品牌可不限库存，前台使用分页、轮播或懒加载。
- 上传前校验格式、体积、尺寸、比例、视频时长；上传后必须同时验证 Directus 文件元数据和 MinIO 对象。
- 无真实媒体记录时保持只读并记录阻塞原因，禁止把旧 PSD 路径包装成可编辑媒体。

## 10. 阻塞与决策

以下任一项出现时，该切片标记为阻塞，不用扩大编辑标记或 fallback 掩盖：缺少真实 Directus 来源、媒体对象不存在、工作台无权限、跨集合不能切换正确表单、公开接口泄漏草稿、无法恢复原值。

需要业务确认的最小问题：

1. 正式素材和文案的提供人、审核人及图片/视频规格。
2. 编辑、审核、发布是否必须三人分离。
3. 新闻日期时区，以及产品/设备/证书/客户的默认分页数量。
4. 哪些当前记录属于演示数据，允许在备份后删除。
