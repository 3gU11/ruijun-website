## 1. 产品定义与边界

Visual Editing 是现有 Nuxt 官网之上的受控内容编辑层。编辑者在真实官网画布中选择区块或元素，在顶部工具栏、左侧页面树和右侧属性面板中修改 Directus 内容，保存为草稿后再审核/发布。

本项目不是任意拖拽建站器。必须保持 Nuxt 原布局、PSD 坐标、动画、路由、锚点、断点和响应式结构；禁止通过 CMS 写入任意 HTML、CSS、JavaScript 或组件代码。位置调整只能使用模板允许的偏移、对齐、裁切焦点和层级等白名单属性，并执行范围校验。

## 5. 绑定、媒体与样式契约

```json
{
  "collection": "product_series",
  "itemId": "1",
  "sectionKey": "series-card",
  "fieldPath": "title"
}
```

- 绑定必须来自 Directus 真实主键，禁止使用数组下标或显示文本猜测。
- `sectionKey` 跨刷新稳定；`fieldPath` 支持嵌套字段和媒体字段。
- fallback、PSD/static 层和未托管外链仅只读，诊断面板必须显示原因。
- 媒体上传需记录文件类型、大小、宽高/时长、首帧状态、对象键和发布状态；失败要可重试且不能留下半成品引用。
- 文本样式只开放模板允许的字体、字号、粗细、颜色、行高、对齐等字段；位置和尺寸同样受白名单与范围限制。

## 6. 编辑器交互与工作流

固定 PC 布局：顶部工具栏、左侧页面/区块树、中间 Nuxt 画布、右侧属性面板。左侧树不得挤入或覆盖画布；选中区块后自动定位并高亮真实 selector。

- 顶部：页面切换、选择/文字/媒体模式、撤销、重做、缩放、保存草稿、预览、状态。
- 画布：双击文字编辑；单击图片/视频打开属性；重复项可新增、复制、隐藏、排序。
- 属性面板：内容、媒体、文字样式、受控位置、绑定诊断。
- 预览采用草稿叠加层；文本/图片优先更新，不等待视频播放结束。
- 取消恢复编辑前值；撤销/重做仅作用于当前会话；网络失败保留本地草稿并允许重试。

工作流：`编辑草稿 → 提交审核 → 审核通过 → 发布`；审核可退回编辑；发布者可回退到历史版本。编辑者、审核者、发布者权限分离（是否兼任待确认）。

## 7. 分阶段执行计划

### P0-A：六页内容闭环（当前批次）

### P0-B：正式媒体闭环（依赖业务素材）

3. 增加格式、大小、像素、时长校验及失败回滚。

### P0-C：真实列表行为

验证新闻展开图文、视频首帧、6 条上限、日期倒序、分页，以及产品/设备/证书/客户/品牌/办事处/里程碑的多条存放和模板展示。
