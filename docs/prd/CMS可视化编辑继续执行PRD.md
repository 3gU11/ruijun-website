## 1. 目标与边界

### 1.1 业务目标

编辑人员在 Directus 的“内容编辑工作台”中，按官网 Header 的六个页面进入真实 Nuxt PC 画布，点击可编辑元素后在属性面板修改内容、受控样式或受控位置，并完成即时预览、保存草稿、刷新确认和原值恢复。

页面范围：网站主页、产品展示、先进制造、视频新闻、关于瑞钧、服务支持。

### 1.2 已确认的产品决策

采用“模板约束的可视化编辑”，不是通用 PPT/自由网页搭建器：

- 中央使用真实 Nuxt iframe，编辑模式下点击仅选中元素，不触发链接、视频播放或折叠。
- 左侧只展示当前页面的业务区块和记录，不能重复 Header 页面分类或塞入整页传统表单。
- 顶部提供选择模式、文字/媒体模式、撤销、重做、缩放、保存、预览与状态。
- 右侧属性面板仅暴露该元素允许编辑的字段、媒体、样式和布局配置。
- 预览与编辑并排，不能覆盖输入区域；视频事件、自动播放失败或加载结束不得阻塞选中和保存。

### 1.3 不能成立的前提

“所有页面可见内容都能任意拖动、缩放、改 CSS”与“不能打乱现有 Nuxt/PSD 布局、动画和响应式”相互冲突。现有页面只允许区块白名单中的文字、媒体、受控偏移、宽度、层级、对齐和显示开关。

若要真正自由拖拽，必须另立新专题页搭建器项目，并承担桌面/移动几何约束、碰撞、版本迁移、回滚和无障碍成本。本 PRD 不把它作为当前六页的交付条件。

## 3. 可视化编辑契约

每个可编辑画布元素必须同时提供以下稳定绑定；任一缺失即只读并显示原因，禁止用可见文字、坐标、数组下标或 fallback 文件名猜测写入位置。

```json
{
  "pageKey": "product",
  "sectionKey": "model-parameters",
  "collection": "product_parameters",
  "itemId": "94",
  "fieldPath": "value",
  "elementType": "text",
  "mediaRole": null,
  "placementKey": null
}
```

| 类型 | 可编辑内容 | 限制 |
| --- | --- | --- |
| 文字 | 内容、字号、字重、行高、颜色、对齐 | 仅限区块白名单和项目字体；富文本必须过滤 |
| 图片/视频 | 已审核媒体、替代文本、标题、焦点、适配方式、海报 | 不接收临时本地路径和任意外链 |
| 布局 | 模板、受限偏移、宽度、层级、显示开关 | 不允许任意绝对定位或改 CSS |
| 列表 | 新增、排序、隐藏、分页策略 | 独立真实 ID；删除须确认且可恢复 |
| 按钮/链接 | 文案、图标、批准链接 | 校验协议、目标和无障碍名称 |

## 5. 状态与权限目标

内容状态：`draft -> in_review -> published -> archived`。

- 编辑者：保存草稿、提交审核。
- 审核者：通过或退回，并记录原因。
- 发布者：发布、下线、回退。
- 公开 Nuxt：仅读取已发布内容；受授权预览会话可读取对应草稿。

本期未完成审核、发布、回退和角色隔离验收，因此不能按生产发布能力验收。

## 6. 执行路线与验收标准

### P0-1B 产品参数写入闭环（已完成）

**目的**：证明画布编辑不是只读预览。

**固定样本**：`product_parameters/94.value`，原值 `1100*800`，对应 FL1180 的“XY 行程”。它是低风险值；不得修改 `model_code` 这类影响路由或匹配的字段。

**步骤**：

1. 受保护 Directus 读取并记录原值、状态与发布时间。
2. 工作台进入“产品展示 -> 型号与参数 -> FL1180 -> 编辑模式”，点击画布参数值。
3. 右侧必须显示 `product_parameters · value`，且目标记录为 `94`。
4. 输入临时值 `1100*800-TDD`；iframe 必须立即更新，“保存草稿”必须可用。
5. 通过工作台保存，受保护 Directus 回读必须等于临时值。
6. 刷新工作台，画布与属性面板仍显示临时值。
7. 通过相同画布/属性面板恢复 `1100*800`，再次回读确认恢复。

**完成证据，2026-08-26**：真实浏览器在“型号与参数 -> FL1180 -> 编辑模式”点击 `XY 行程`值，属性面板显示 `product_parameters · value`；输入 `1100*800-TDD` 后 iframe 立即显示 `1100*800-TDD mm` 且“保存草稿”可用。工作台保存成功，认证 Directus 回读记录 `94` 为临时值；整页刷新并重新进入型号后仍显示临时值。随后使用相同画布路径恢复 `1100*800`，认证 Directus 最终回读为 `{"id":94,"value":"1100*800","status":"draft","publication_state":"unpublished"}`。无测试值残留。

**测试证据**：CMS 定向回归 `260/260` 通过；工作台的保存请求与刷新后的 `product_parameters` 读取均为 HTTP `200`。HTTP 状态本身不构成完成证明，完成判断以上述认证记录内容和画布刷新结果为准。
