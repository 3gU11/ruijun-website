# 瑞钧官网 CMS 可视化编辑媒体绑定修补 PRD

## 1. 文档定位

本文修补《CMS 可视化编辑继续执行 PRD》和《CMS 可编辑内容清单与视觉控制规范》，专门处理“页面能显示图片，但画布无法选中、替换或保存”的缺口。

本文不扩大官网视觉布局、动画、响应式断点或自由拖拽范围，只补齐已有编辑承诺的媒体识别、选择、保存和验证闭环。

## 2. 当前问题

1. 首页三大理由的发布内容来自 `homepage_sections`，但画布目标解析和媒体筛选主要按 `pages` 处理。
2. 静态 PSD、CSS `background-image` 和默认图片可以显示，却没有明确区分“可编辑媒体”和“展示用静态资源”。
3. 页面模板可能有 `data-cms-preview-*` 属性，但集合、记录 ID、字段路径、媒体位置和保存回读未必成套存在。
4. 源码契约测试不能替代真实的认证 Directus 回读。

## 3. 目标与非目标

### 目标

- 所有已承诺可替换的图片明确进入 `可编辑`、`只读/待媒体`、`待建模` 或 `不可编辑装饰` 状态。
- 可编辑媒体点击后定位到唯一的 `collection + itemId + fieldPath`。
- 媒体候选按页面、区块、媒体类型、用途和草稿授权过滤。
- 保存后通过认证 Directus API 回读，刷新工作台和预览后仍显示新媒体。
- `pages` 与 `homepage_sections` 两种来源不串写。

### 非目标

- 不开放任意 CSS、HTML、脚本、外链地址或自由像素拖拽。
- 不把现有 PSD 或 `website/public/assets` 自动升级为正式 CMS 媒体。
- 不改变图片裁切算法、动画时序或移动端布局，除非绑定缺陷阻断内容显示。

## 4. 媒体状态模型

| 状态 | 条件 | 画布行为 | 工作台行为 |
|---|---|---|---|
| 可编辑 | 有真实集合、记录 ID、字段路径和受管媒体 | 可选中 | 显示候选媒体并允许保存 |
| 只读/待媒体 | 图片存在但没有合格媒体记录 | 可选中并显示原因 | 不显示可写假象 |
| 待建模 | 图片用途或字段尚未定义 | 不进入普通编辑流程 | 显示待建模原因 |
| 不可编辑装饰 | Logo、纹理、动画遮罩等固定资产 | 不显示编辑框 | 不进入媒体选择流程 |

有图片 URL 不等于可编辑。四项绑定缺一不可：集合、记录 ID、字段路径、受控媒体用途。

## 5. 绑定契约

每个可编辑媒体元素必须输出：

```text
data-cms-preview-collection
data-cms-preview-item-id
data-cms-preview-field-path
data-cms-preview-media-role
data-cms-preview-placement-key
```

- `collection` 必须是真实 Directus 集合。
- `itemId` 必须是真实记录 ID，不能用数组下标替代。
- `fieldPath` 必须是记录内可写字段，例如 `media.0`、`assets.1` 或 `configuration.drawings.0.media_asset_id`。
- `mediaRole` 使用 `background`、`foreground`、`gallery`、`icon`、`cover`、`video` 等受控值。
- `placementKey` 使用用途白名单，例如 `home.reason.background`、`about.hero.background`。

集合规则：

| 页面内容 | 允许集合 |
|---|---|
| 页面段落 | `pages` |
| 首页独立理由和横移内容 | `homepage_sections` |
| 产品媒体 | `product_series`、`product_models`、`product_parameters` |
| 新闻媒体 | `articles`、`media_assets` |
| 关于、制造、服务业务媒体 | 对应业务集合或页面段落 |

## 6. 必须覆盖的范围

### P0：首页三大理由

覆盖 `performance`、`advanced-manufacturing`、`industry-leadership`：

- 背景图：`home.reason.background`；
- 设备前景图：`home.reason.machine`；
- 横移图标：`home.reason.icon`；
- 标题、正文、短标题和链接；
- `pages` 与 `homepage_sections` 均可识别；
- 背景、前景、图标不得互相显示错误候选。

### P0：首屏和时间轴

- 首页首屏视频、海报、结束静帧；
- 首页/关于页共用时间轴背景、节点图标和里程碑佐证；
- 首屏静态回退图没有媒体记录时显示只读原因。

### P0：关于和服务

- 关于页首屏共享背景与机器前景；
- 工厂、资质、荣誉、专利、合作品牌、客户图库；
- 服务首屏、入口图标、区域图片和地图。

### P1：产品、制造、新闻

- 产品封面、设备主图、特性图、工程图、技术标签；
- 制造首屏、工艺节点、核心设备图库；
- 新闻封面、视频、海报和正文媒体。

### 明确标记为只读或待建模

- 关于页 `about-psd/banner.jpg`、`about-psd/legacy.jpg`；
- 时间轴纸张纹理；
- 首页固定装饰机器图和动画变形图；
- 固定 Logo、PSD 装饰层和没有 CMS 字段的默认图片。

## 7. 编辑工作流

1. 打开草稿页面和官网实时预览。
2. 点击媒体元素，读取集合、记录 ID、字段路径、角色和用途。
3. 缺少绑定时显示只读、待媒体或待建模原因。
4. 完整绑定时只显示匹配的候选媒体。
5. 选择后预览立即更新，未保存值只存在当前草稿。
6. 保存后认证回读正确集合、记录 ID 和字段路径。
7. 刷新工作台和预览，确认媒体仍正确显示。
8. 测试完成恢复原值并清理临时记录。

## 8. 验收标准

### 绑定

- 点击首页三大理由背景，属性面板显示真实 `homepage_sections` 或 `pages`、记录 ID 和字段路径。
- 背景、前景、图标分别得到正确 `placementKey`。
- 未绑定静态图不能出现可写媒体选择器。

### 替换闭环

每个 P0 媒体位置至少完成一次：点击选中、选择临时媒体、预览立即更新、保存、认证回读、刷新确认、恢复原值。

### 隔离

- 修改背景不得改变图标、前景或其它理由。
- 修改 `homepage_sections` 不得写入 `pages` 同名区块。
- 产品、新闻、关于、服务媒体不得串写到首页。
- 私有草稿媒体只在授权预览可见。

### 测试

- 单元测试覆盖集合、字段路径和每个 `placementKey`。
- 契约测试覆盖只读原因和跨集合隔离。
- 至少一条真实浏览器测试覆盖首页三大理由背景替换、保存、回读、刷新和恢复。
- 测试报告不得以 HTTP 200、截图或静态 fallback 代替认证回读。

## 9. 实施切片

### P0-A：统一页面媒体身份

- 加载和维护 `homepage_sections` 草稿记录；
- 扩展画布目标解析、活动草稿切换和保存回写；
- 统一 `slug/page_key` 页面身份；
- 增加跨集合串写保护。

### P0-B：完成媒体位置解析

- 为首页背景、前景、图标建立独立解析器；
- 统一候选过滤和预览授权；
- 为无绑定资源返回只读原因。

### P0-C：完成浏览器闭环

- 首页三大理由背景真实替换；
- 时间轴和关于页首屏各完成一项媒体闭环；
- 完成回读、刷新、恢复和临时数据清理。

### P1：扩展其它页面并更新绑定台账

- 产品、制造、新闻、服务逐页复核；
- 每个静态/PSD 图片列入可编辑、只读或待建模清单；
- 更新现行 PRD、绑定台账和运营说明中的状态。

## 10. 完成定义

媒体项只有同时满足以下条件，才能标记为“已接入”：模板绑定完整、编辑器可选中、候选过滤正确、保存写入正确集合和字段、认证回读成功、刷新后预览一致、原值恢复成功、测试和绑定台账已更新。
