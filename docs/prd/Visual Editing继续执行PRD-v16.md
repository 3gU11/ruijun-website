# 瑞钧官网 Visual Editing 继续执行 PRD

- 版本：v16.0
- 日期：2026-08-25
- 状态：执行基线，未宣称 P0 完成
- 上一版本：`Visual Editing继续执行PRD-v15.md`
- 适用范围：PC 端六页可视化编辑；手机端只读回归

## 1. 本版结论

本期交付的是“在现有 Nuxt 官网画布上编辑 CMS 内容”，不是重做官网，也不是开放任意拖拽的建站器。页面模板、原布局、PSD 坐标、动画、路由、锚点和响应式结构继续由 Nuxt 拥有；CMS 只管理已登记的文字、媒体、重复项和受控视觉参数。

当前代码、自动化测试和生产构建已有较多基础能力，但真实 Chromium 中的画布更新、保存回读、刷新保持、媒体对象和发布流程仍需重新签收。以下状态严格区分：

| 状态 | 含义 |
| --- | --- |
| 已实现 | 源码或自动化测试已有实现，不代表真实数据闭环 |
| 待验收 | 需要登录态、真实浏览器或 Directus/MinIO 证据 |
| 待建模 | 页面存在可见内容，但尚未完成唯一 CMS 来源和绑定 |
| 只读 | 为保护模板或缺少绑定，当前只能预览 |
| 延期 | 不纳入本期 P0 |

## 2. 产品目标与非目标

### 2.1 P0 目标

1. 工作台按“网站主页、产品展示、先进制造、视频新闻、关于瑞钧、服务支持”六个一级页面组织，二级为真实页面区块。
2. 在同一个全宽工作台中完成选择、定位、编辑、临时预览、撤销/重做、保存草稿和刷新回读。
3. 每个可编辑元素具备唯一绑定：`collection / itemId / sectionKey / fieldPath`。
4. 文字、图片、视频、列表排序、分页和白名单视觉参数可形成真实闭环。
5. 草稿、审核、发布、回退与公开读取隔离，失败可重试且不丢原值。
6. 不改变 Nuxt 的非内容行为和视觉结构。

### 2.2 非目标

- 任意 HTML/CSS/JavaScript 编辑、自由像素拖拽或 PowerPoint 式重排页面结构；
- 手机端可视化编辑；多人实时协作、模板市场、生产 CDN/转码平台；
- 用“HTTP 200 或自动化测试全绿”替代真实浏览器和数据回读验收。

## 3. 系统边界与数据所有权

```text
Nuxt 模板层（布局、坐标、动画、路由、响应式）
        ↓
Visual Binding 层（选择、高亮、定位、临时状态、历史、受控样式）
        ↓
Directus（内容、媒体、权限、审核、版本、发布）
        ↓
MySQL 127.0.0.1:3307 + MinIO 9000/9001
```

- 页面结构和动画只能在 Nuxt 修改。
- Directus 记录是业务内容唯一主来源；fallback 只能标记为只读。
- 媒体只保存 Directus 文件引用，不保存本地路径或任意外链。
- 公开 BFF 只返回已发布内容；草稿仅通过授权预览读取。

## 4. 工作台交互契约

```text
顶部工具栏：页面/区块、选择、文字、媒体、撤销、重做、缩放、保存、预览
左栏：六页 → 页面真实区块
中栏：真实 Nuxt PC 画布（选择、高亮、滚动定位）
右栏：内容、媒体、版式、文字样式、响应式属性
```

| 能力 | 验收标准 |
| --- | --- |
| 画布布局 | `1440x900` 时右栏展开仍保留至少 720px 画布；面板不得覆盖画布 |
| 选择定位 | 点击区块或属性项，画布滚动到真实锚点并高亮；缺锚点明确报错 |
| 文字编辑 | 双击画布文字或编辑右栏，双方即时同步 |
| 实时预览 | 本地修改后 300ms 内开始更新，不整页刷新，不等待视频结束 |
| 媒体编辑 | 只能选审核素材；可设置海报、焦点、`cover/contain`、替代文本 |
| 历史 | 撤销、重做、取消同时恢复面板、画布和本地草稿状态 |
| 受控视觉 | 只开放模板、排序、对齐、字号、字重、颜色、行高、有限偏移等白名单 |

## 5. 六页内容模型

| 页面 | 二级区块和 P0 对象 |
| --- | --- |
| 网站主页 | 首屏视频/海报、三大理由、产品系列、横移图文、时间轴、页尾 |
| 产品展示 | 首屏、分类筛选、系列/型号、卖点、参数、单位、尺寸图、资料、分页 |
| 先进制造 | 首屏、工艺画布背景/节点/连接标签、制造区域、核心设备图库 |
| 视频新闻 | 首屏视频、动态新闻、视频分享、详情正文、封面和日期 |
| 关于瑞钧 | 品牌故事、共用时间轴、厂区/认证/荣誉/专利图库、合作品牌、国内外客户 |
| 服务支持 | 首屏、瑞钧支持、型号入口、服务入口、区域图、办事处/门店/负责人 |

约束：新闻和视频分享各每页最多 6 条，按业务发布日期降序；产品、设备、证书、客户等库存可扩展，但前台必须分页、轮播或懒加载。首页与关于页时间轴共用一份里程碑数据，只允许各页保存展示配置；页头、页尾和全站 CTA 只维护一份。

## 6. Visual Binding 契约

```json
{
  "collection": "pages",
  "itemId": "1",
  "sectionKey": "performance",
  "fieldPath": "body",
  "elementType": "text",
  "mediaRole": null,
  "placementKey": null
}
```

- 四个身份字段任一缺失即只读；`itemId` 必须来自 Directus 响应。
- 重复项使用真实记录 id 或稳定源索引，禁止用排序后的数组下标写回。
- 提交前校验集合、记录、字段、版本和权限；不存在的路径不得自动创建。
- 跨集合保存逐项返回结果；部分失败可单项重试，成功项不得重复写入。
- 画布、属性面板、请求和回读值不一致时禁止显示“保存成功”。

首页首个验收样本固定为：`网站主页 / 三大理由 / 增效降损正文 → pages / 1 / performance / body`。

## 7. 媒体与视觉规格

图片和视频“无限存放”只表示素材库和业务记录可扩展，不表示一次性渲染全部内容。建议规格作为上传提示和发布校验：

| 用途 | 建议规格 |
| --- | --- |
| 首屏背景 | 桌面 16:9、至少 2560×1440；WebP/AVIF/JPG，建议 ≤3MB |
| 产品/设备主图 | 1:1 或 4:3、至少 1600×1200；PNG/WebP/JPG，建议 ≤2MB |
| 新闻封面 | 16:9、至少 1600×900；WebP/JPG，建议 ≤1.5MB |
| 证书/尺寸图 | 原始比例、长边至少 2000px；PNG/JPG/PDF，建议 ≤10MB |
| 首屏视频 | MP4 H.264/AAC、1920×1080、15–60秒，建议 ≤80MB；必须有海报 |
| 新闻/分享视频 | MP4 H.264/AAC、1920×1080；建议单条 ≤30分钟/300MB；可配字幕 |

视频先显示海报和文字，播放、失败或被阻止都不得阻塞编辑。默认可取首帧，但必须允许人工替换海报。

## 8. 状态、权限与发布

```text
草稿 → 待审核 → 已批准 → 已发布
          └────→ 已退回 → 草稿
已发布 → 新版本 / 回退
```

内容编辑可改草稿；审核人员核对版权、规格和业务文案；发布人员只能发布批准版本。权限必须在 Directus API 层执行。宣传数字、证书、专利、客户 Logo、电话和负责人必须有业务确认人。
