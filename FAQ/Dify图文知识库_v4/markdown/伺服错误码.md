# 伺服报错 E-010 — 固件版本不匹配

**报警大类**：01类（面板与CPU通讯错误）
**报警发生时伺服状态**：伺服run
**可清除**：是（需上电生效）

## 报警说明
下载的固件版本与当前驱动器不匹配，导致系统无法正常加载固件。

## 可能原因
- 下载的固件版本错误，与当前驱动器型号/硬件版本不兼容。

## 解决方法
- 与代理商或厂家联系，确认并下载与当前驱动器型号匹配的正确固件版本。
- 重新刷写正确的固件。

# 伺服报错 E-030 — 母线电压过压

**报警大类**：03类（电源电压异常）
**报警发生时伺服状态**：伺服off
**可清除**：否

## 报警说明
驱动器母线电压 U0-05 高于实际预设阈值。
- **220V供电机器**：U0-05 ≥ 402V 时报警
- **380V供电机器**：U0-05 ≥ 780V 时报警

## 可能原因
- 电网电压过高
- 负载转动惯量过大（制动能力不足）
- 制动电阻损坏或阻值过大
- 加减速时间过短

## 解决方法
1. **连接外置制动电阻**：
   - 220V：U0-05=392放电开始，U0-05=377放电结束
   - 380V：U0-05=750放电开始，U0-05=720放电结束
2. **增加加减速时间**
3. **减小负载惯量**
4. **降低启停频率**
5. **更换更大功率驱动器与电机**
6. **检查制动电阻**，更换阻值合适的外置电阻
7. 检查电网波动情况：
   - 220V驱动器正常电压范围：200V~240V
   - 380V驱动器正常电压范围：360V~420V
   - 若电压波动大，建议使用正确电压源和稳压器

# 伺服报错 E-040 — 母线电压欠压

**报警大类**：04类（电源电压异常）
**报警发生时伺服状态**：伺服run/off
**可清除**：否

## 报警说明
驱动器母线电压 U0-05 低于实际预设阈值。
- **220V供电机器**：U0-05 ≤ 150V 时报警
- **380V供电机器**：U0-05 ≤ 300V 时报警

## 可能原因
- 正常上电时报警：电网电压过低
- 发生瞬间断电
- 驱动器内部采样电路硬件故障

## 解决方法
1. **检查电网波动情况**：
   - 220V驱动器正常电压范围：200V~240V，若电压波动大，建议使用稳压器
   - 更换更大容量的变压器
2. **瞬间断电**：待电压稳定后重新上电
3. **硬件故障判断方法**：
   - 万用表AC档测量伺服LN（R/S/T）进线值，正常220V±10%
   - 伺服bb状态下监控U0-05
   - 若万用表测量的电压×1.414 > U0-05（误差10V之内），则伺服驱动器有故障，需要寄回检修

**可清除**：否

8. **重新调整增益参数**。

# 伺服报错 E-264 — 振动过大

**报警发生时伺服状态**：伺服run
**可清除**：否

## 报警说明
检测到系统振动过大。判断标准：当脉冲指令结束后前三个波峰速度值连续不小于300rpm达到3次，则驱动报警。

## 可能原因
1. **受到外力影响导致振荡**。
2. **负载惯量大而负载惯量比设置错误**或者**增益过小**导致定位振荡。

## 解决方法
1. **检查外力来源**，查看机械安装是否存在问题。
2. **增加伺服增益**提高抗扰动能力。
3. **采集速度曲线分析**振荡原因。
4. 当脉冲指令结束后前三个波峰波谷成收敛状态时（0.8×|第一次峰值|＞|第二次峰值| 且 0.8×|第二次峰值|＞|第三次峰值|），驱动不应报警，可调节相关阈值。
5. **联系厂家技术支持**。

3. EtherCAT通信线缆配线有问题或线上有过度噪音。

## 解决方法
1. **确认来自上位装置的PDO送信时间是否固定**（是否中断）。
2. **确认PDO看门狗检出延时值**是否太大。
3. **确认EtherCAT通信线缆配线**是否有问题，线缆上是否有过度噪音。**更换优质网线**。
4. **通讯线缆重新连接**，网线悬空，与动力线分开。
5. **关闭焊机类干扰设备**再运行，以排除干扰问题。
6. **交叉测试判断故障点**。
7. 可通过伺服面板 **F0-00=1** 来清除报警。

# 伺服报错 E-883 — 不正常动作异常保护

**报警大类**：EtherCAT通讯异常
**ESC寄存器AL Status Code**：0000h

## 报警说明
探针功能端子未分配时选择了外部触发，或电子齿轮比计算结果超出允许范围。

## 可能原因
1. 输入信号EXT1/EXT2未分配时，通过Touch probe function选择了外部触发。
2. 电子齿轮比的分母或分子无符号超过31bit/64bit/32bit。
3. 电子齿轮比最终计算结果在8000倍~1/1000倍之外。

## 解决方法
1. **确认探针功能端子分配** P5-62/P5-63是否正确。
2. **确认电子齿轮比设置是否正确**。
- 可通过伺服面板 **F0-00=1** 来清除报警。
